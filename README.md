# Vellum SDK

Adapter-neutral embedding contracts, session orchestration, and interaction
model for the Vellum semantic engine. Concrete filesystem, serialization,
Unicode, clipboard, and presentation implementations live in sibling projects.

Local development resolves exact-version path dependencies through the sibling
`vellum` and `vellum-adapters` repositories. Published packages use the same
exact versions without relying on those paths.
