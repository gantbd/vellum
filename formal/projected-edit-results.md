# Existing native annotation and reversal result values

Released results are not always full private receipts. Annotation identity/version
disclosure and undo/redo target disclosure use their existing captured/current
native grants. The checker preserves these projections rather than demanding
withheld fields or exporting private authority.

The annotation envelope contains an unavailable result, a confirmed nonpublication
decision, or an applied/unchanged projection with its exact identity/membership
fields. Content version and target generation are independently optional. Create
and delete cannot be unchanged. Reversal has no unchanged result; its applied
projection may omit the target and never contains the private authority field.
Publication references remain correlated to the original invocation.

The existing native producer/release corpora produce 1,695 replies through 27
controls. Every sampled read leaves the producer root and reported usage unchanged.
There are 25 observed projection shapes; 117 structural positives and 2,259 malformed
cases bring the complete checker corpus to 4,071. Tests include exact fields,
UTF-8/safe integer boundaries, optional-field removal, nested identity/target
checks, hidden/symbol/accessor rejection and enum noncoercion. Four witnesses
show that valid copied values do not confer original-ticket or current authority.

Twenty-four pure-checker mutations evaluate the same complete corpus. Native
production runs once before checker variants because only the stateless checker
is mutated. Import, construction and tool errors are not semantic detections.
Validation-only substrate checks intercept 143 filesystem/process callables after
imports and corpus construction, with no baseline calls and three detected
injections. They do not cover native production, imports or arbitrary host code.

The checker assumes prebounded native frames; property reflection does not prove
raw-ingress or physical allocation bounds, and arbitrary proxies are not isolated.
It supplies no new public query, F06 result facet, codec, disclosure grant or
result-acquisition mechanism. It is not integrated into native construction or
observer installation. Existing authority, original handles, captured/current
facets, whole-reply reservation and protected cleanup remain independent.

IF-01/02, PATH-02 and INS-01/03/08/12/13 retain bounded validation/release/fault/
cleanup observations. MELT/golden/RED/USE and STRIDE/LINDDUN/privacy/hazard coverage
must distinguish shape failure from execution failure without raw identities,
targets, field names or payload labels. This artifact installs no telemetry path.
The selected static engine/reference graph remains 116; full frozen qualification and endpoint audit,
public mapping/integration and operational/independent gates remain open.
