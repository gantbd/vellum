## Ownership and resolution

[engine-settings-state.mjs](engine-settings-state.mjs) compiles bounded plain data
into immutable schemas, restrictions, layers, target associations and resolutions.
Every schema explicitly declares sensitivity; the declaration grants no access.
Six closed types reject unknown fields, callbacks and recursive schema references.
Traversal and copied input are bounded by explicit profiles. Accessor inspection
does not execute getters; hostile Proxy/preallocation/physical-time behavior is
outside the normalized-input premise.

Scope precedence is host, language, workspace, document, view. Source, serialization
and analysis are semantic domains; presentation preference domains are rejected.
Target associations are accepted logical inputs, not verified workspace facts.
Equal-rank conflicts cannot hide beneath a higher override. Origin-only changes
advance metadata without invalidating unchanged effective semantic domains.

[JSON Schema core §4.2.2](https://json-schema.org/draft/2020-12/json-schema-core#section-4.2.2)
provides the precedent for JSON instance equality: mathematical numbers, ordered
arrays, unordered object properties and exact code-point strings. This is not a
complete JSON Schema implementation or byte-fidelity claim. Native intent reuse
separately distinguishes negative zero. Existing ordered configuration precedent
and owner separation remain in specification §§22.3/28.33–28.34.

## Native execution and retention

Private preparations bind actual invocation owner/domain/ticket and immutable
intent/context/profile. Preparation captures affected interpretation, targets and
all contributing layers, unioning mandatory and extra read predicates. Service
revalidates current authority, context, root facts and dependencies, then merges
into the current root without restoring unrelated state. Copied or foreign tokens
carry no authority. Settings is the twelfth closed native job kind; it uses the
existing common publication mechanism rather than a second mutation authority.

Actual immutable context leases and preparations occupy an owned pool charged
against the parent's remaining declared logical budget. Release cannot refund
ever-issued capacity; closed retirement cannot reopen. Internal reads are trusted
composition only, not the unfinished recipient-facing value/origin projection.
Host policy facts, real consumer behavior and actual association truth remain
explicit premises. Neither budget arithmetic nor leases establish physical RSS,
concurrency safety or crash durability.
