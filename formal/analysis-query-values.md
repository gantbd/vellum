# Existing analysis query reply values

F08 already returns captures, an analysis summary, or unavailable. The bounded
reply checker describes those existing values; it does not release a snapshot,
query a provider, authenticate a producer or acquire permission. Both query
variants retain their existing operation meanings. No public request, codec,
discovery profile, point query or instrumentation pathway is introduced.

Unavailable contains only its status. A successful reply contains context, parse
state and coverage; only supported-analysis contains captures. The context binds
document/source revision, analysis identity, five grammar/query/registry/settings
generations and the existing pinned language profile. Identity strings and
nonnegative safe integers follow this native producer's rules, including zero
incarnations/generations. These are not new universal coordinate, identity or
interchange defaults.

Captures are dense ordered four-element tuples: a closed layer, a lossless UTF-8
tag and positive byte span. Empty tags and an empty captures array remain legal.
Adjacent captures are legal; overlap, backward order, sparse arrays, extra fields,
accessor fields and zero-width spans refuse. Parse state and coverage keep their
existing independent closed alternatives. Descriptor inspection does not invoke
ordinary getters; proxies and raw unbounded JavaScript input are outside scope.

The corpus captures 2,019 actual replies from the existing analysis owner across
all fourteen pinned mixed-language packets and the 88-control producer corpus.
Each intercepted query preserves its normalized state and reported owner usage.
Released values are copied immediately for the checker corpus. Fifteen additional
structural positives and 155 malformed cases give 2,189 total cases. Five controls
cover the two operation/result correlations, producer-compatible boundaries and
zero observed getter calls. Two native refusals demonstrate that a copied snapshot
or revoked grant cannot obtain a result even when the copied result's shape is
valid. Shape does not prove original authority or current source binding.

Twenty-four pure checker mutations fail semantic assertions. The native corpus
is constructed once and reused across checker variants. Verification-only getter
counters reset for each variant; the unchanged baseline passes again afterward,
so one mutant's observation cannot contaminate later detections. Construction,
import, tool errors and unrelated runtime exceptions do not count as detections.

These are already bounded normalized frames. Work is bounded by their finite
capture/field counts; descriptor enumeration has temporary storage costs. No
physical/global workspace bound, hostile-proxy isolation or production allocation
claim follows. Native owner release/fault integration, complete public products,
current frozen qualification and endpoint adoption remain separate obligations.
The native query now installs this check before release, with original packet
context/parse-state/coverage correlation. Previously delivered information cannot
be revoked by a later failure; the older pure-checker corpus does not by itself
prove this new integration.

## Actual owner release and query workspace

The selected analysis registry prepays each task's existing captured/evidence
obligations. A query now separately borrows two declared construction-sized logical
frames against actual remaining owner maxHeldBytes before inspecting input/facts.
Let F be maxEnvelopeBytes plus the larger serialized status-only success header.
The accepted packet bounds retained context/parse-state/coverage/captures. A query
removes source/regions and selects/clips positive integer endpoints. Ordered
nonoverlapping captures permit at most one increased lower endpoint; any decimal
growth is bounded by source length's decimal width and paid by the omitted source
byte array. Decreased upper endpoints cannot grow. Adding the status therefore fits F, even
for a zero delivery ceiling. Four assembly probes cover both operations with zero
and one-byte maxReplyBytes. These limits refuse delivery without owner fault or
exceeding the construction frame. Existing task frames are not borrowed for output.

For held H, ceiling C and finite safe Q = 2 × F, admission requires
Q ≤ C − H. During the serialized call, H + Q ≤ C. A busy guard excludes owner
query/admit/submit/accept/intake/control/retire mutation; normal completion or caught
fault returns Q exactly once. These are logical normalized frame units, not
descriptor-object/allocator peaks, base metadata sizing or complete shared accounting.

The existing value validator runs on the actual reply after its size check and
before delivery. Original packet context, parse state and coverage also match.
An unexpected query failure or invariant violation latches the owner's absorbing
fault fence, blocking new data-plane work/reads. It preserves original tasks,
spent origins, leases and evidence. It does not accuse the external provider of
contradiction, alter source or fault the editing domain. After the borrow ends,
protected cancellation, late authenticated receipts/quiescence and justified
retirement still discharge actual obligations. A fault or unavailable reply alone
does not refund them or prove quiescence; no restart/replay policy is added.

The per-call machine is idle → querying → idle or fenced. A fenced owner permits
protected evidence/control/discharge, not renewed query eligibility. Fixed two-form
dispatch and bounded capture/tuple/context walks give conditional finite execution
under the existing serialized inert-data premises. They do not prove whole-engine
categorical closure, eventual provider return or hostile JavaScript containment.

Five controls exercise both native operations, exact below/at/above headroom,
ten corrupt-result/exception cases, seven reentry seams and retained protected
drain. Eight semantic mutations challenge guard, context correlation, frame count,
delivery-limit underfunding, reentry, fault latch, temporary refund and protected retirement. Construction/tool
failures are not detections. Existing 88 producer controls/21 mutations and the
2,189-case/24-mutation value corpus pass focused regression. Full frozen
qualification and endpoint adoption remain required.

IF-02 and INS-03/05 retain current release, successful empty delivery, unavailable,
