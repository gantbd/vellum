# Native annotation and combined context evidence

The selected F02/F03 path prepares permitted annotations, optionally with source
from one actual owner root, then installs a separately charged native context.
Section 15.4.3 connects selected synchronous F05 child ownership through this
issuer; see native-combined-search.md. Section 12.8.7 supplies exact retained
projection copies and class narrowing. Broader historical/version-set profiles remain
integration gates. No public verb, transport, UI policy or numeric default is added.

## Authority and ownership

Only the actual root supplies bodies, versions, placement and source bytes.
Complete bounded host grant rows select visible records and body/target facets;
they cannot supply content. Annotation-only capture neither requires source
permission nor retains source bytes. Combined capture requires both classes and
retains the source-product profile with its bytes.

Scope binds document incarnation, recipient, purpose, destination, policy,
continuity and interpretation. Current projection authority covers the entire
captured facet domain; matching labels or source permission do not establish it.
Host identity, policy truth, visibility/order completeness and notification remain
accepted premises. Native selector possession is not authority.

Installation validates the original private cut, exact scope, current eligibility,
actual liveness, capacities and complete reply/selector envelopes. Stage both
registry maps before consuming the cut once. Inert copied facts and a frozen
reply leave local nonallocating assignments under the synchronous no-reentrancy
premise. Ordinary refusal consumes nothing; a precommit surprise fences the owner
without partial live registration. The installed context retains owned values
while its preparation pool discharges. This transfer does not grant a policy lease.
Trusted owner inspection helpers are not recipient query products.

## Queries and retirement

F03 enumeration, inspection and target-location reuse the existing annotation
producer. Internal positions never become public record IDs or continuations.
Original native selectors bind exact context and kind; continuations also bind
page limit/position. Reserve the whole page's selectors, metadata and reply before
registration/handoff. Retries reuse live selectors; refusal exposes no subset.
Combined F02 range/line queries use the same cut and captured source profile.

Validate recognized shape, scope, selector binding and source coordinates before
observing loss. Accepted exact-false authority, continuity, liveness, stop,
projection or retention loss closes delivery irreversibly. Actual disposal/fault
also fences it under stale positive facts. Both classes remain required for a
combined context. Unknown/truthy facts and transient resource refusal deny without
establishing loss. New ordinary publication never refreshes captured values.

Invalidation refunds neither capacity nor lifetime issuance. Protected context
retirement removes every dependent selector. Empty-pool retirement refunds its
reservation once without reopening the issuer. No physical-erasure, allocator or
worker-quiescence claim follows.

## Logical reservation arguments

The preparation profile reserves the following declared logical envelope:

    profileBytes + 2*maxRequestBytes + 2*maxCaptureBytes + 2*maxContextBytes
      + maxPrepared*(2*maxCaptureBytes + maxContextBytes + maxSelectorBytes)

The installed-context profile reserves:

    profileBytes + 2*maxRequestBytes + 3*maxCaptureBytes
      + 2*maxContextBytes + 3*maxReplyBytes
      + maxContexts*(2*maxCaptureBytes + maxContextBytes + maxReplyBytes)
      + (2*maxSelectors + maxHolds)*(maxSelectorBytes + maxSelectorRecordBytes)

The selector term covers live and candidate registry frames; the hold term covers
bounded F05 lease metadata referencing the retained context. Input/preparation
workspace remains reserved at zero retained capacity. Opening compares local
limits with actual parent headroom; the parent separately owns root/invocation
frames. These units are not measured heap sizes or complete host/global accounting.

## Instrumentation and remaining gates

IF-02/03/PATH-02 separate preparation, installation and content handoff.
INS-01/03/08/13 distinguish admission, release, retained obligations and protected
control; context registration is not authored INS-02 publication. Observe bounded
operation/disposition latency, errors, saturation and issuance exhaustion, never
bodies, source, annotation/recipient IDs or selectors. MELT/golden/RED/USE signals
remain subordinate to security/privacy projection; diagnostics grant no authority.

Actual clocks, installed telemetry, overhead/SLOs, policy/identity and complete
notification need separate evidence. Historical/version-set profiles,
full public codecs/results/events, production
concurrency/crash behavior and independent assurance remain required. This closes
no whole residual family. Adoption requires specification/model/harness
reconciliation and a fresh full frozen run.
