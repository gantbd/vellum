# Resource catalog query arguments

The existing F07 capabilities profile resource-catalog-query/1 now has a bounded
typed/dynamic argument normalizer. It preserves scoped-resource-catalog/1 and its
native list/inspect vocabulary. Configuration-query/1 remains a different profile
of the same semantic variant. No operation, acquisition verb, wire encoding,
network route, UI policy or filesystem procedure is introduced.

## Closed syntax and original identities

The native reader and normalizer share immutable outer and nested field
declarations. The outer request contains contract, capabilities operation,
original context, fixed profile and nested request. List has a positive safe
integer limit and null or original continuation; inspect has an original entry
reference. Request membership is checked only after confirming a string verb,
without invoking a caller-provided coercion hook. Unknown fields and verbs refuse.

Retain original context and selector objects separately from owned ordinary data.
Canonical JSON shadows contain null in the opaque positions and explicit role
labels; null first-page continuation remains distinct from a retained selector.
Do not traverse, clone, swap or reconstruct handles. Object shape does not
authenticate them. The producer restores the original roles to the unchanged
native request and retains the selected typed or dynamic route.

Capture the complete eight-field authority context and exact finite byte/node/
depth limits. Each envelope, authority and final canonical capture has an
independent bound; the effective byte ceiling intersects the caller's requested
limit with the admitting maximum. Copied records are immutable, and producer
output cannot mutate them. Equality of normalized meaning includes original
context/selector identity and owned ordinary request, authority and limits.

Ordinary records reject accessors, symbols, hidden fields, foreign prototypes,
cycles and invalid normalized strings. Opaque internals remain uninspected. This
uses the established trusted in-process descriptor/copy boundary, not a claim of
containment against arbitrary JavaScript proxies or hostile runtimes.

## Native release and ownership remain separate

Normalization establishes argument meaning, not native admission or permission.
The actual reader still checks original context and selector lookup, complete
scope, current prepared-root visibility, captured ceilings, current release and
observed absorbing loss. A positive safe limit larger than the actual page
profile can normalize but must refuse natively; normalization does not raise it.
Entry and continuation roles cannot substitute for each other or for a context.

Preparation cuts remain explicitly disposable after refused calls. Context stop,
retention release, delivery drain, registry ownership and spent lifetime issuance
retain their native rules. This slice does not connect a charged decoding gateway,
change the registry's logical reservation or establish physical/global accounting.
Native result validation, full discovery products and actual-parent gateway
ownership remain separate obligations.

## Instrumentation and scoped evidence

IF-01/02, PATH-02 and INS-01/03/05/08/09/12/13 distinguish argument recognition,
capture/refusal, native release, current invalidation and protected cut/context/
registry discharge. MELT/golden/RED track those distinct pathway populations;
USE distinguishes declared ownership, saturation and refusal. STRIDE, LINDDUN
and privacy/hazard checks include verb/field injection, role substitution,
post-capture mutation, cross-context pagination and registry-linkage disclosure.
Raw requests, selectors, provider/resource identities, metadata and policy facts
must not be ordinary telemetry labels or fault payloads. No numeric threshold or
new signal is selected.

Eight controls cover first-page, continuation and inspect products on both routes:
six native compositions, 120 malformed refusals, 36 exact independent capture
boundaries and eleven opaque-role cases. Twenty-seven mutations run against a
coherent copied-graph baseline. The earlier full native corpus retains 21 controls
and all forty mutation controls after exporting its shared declarations.
Construction, syntax and process/tool failures do not count as semantic mutation
detection. Full frozen qualification and endpoint reconciliation remain adoption
gates. Other resource/created-reference products, implementation, supported-host
and operational/independent assurance obligations remain open.
