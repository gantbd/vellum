# Fresh basis selectors for settings lifecycle

Specification §22.3.1.11 reuses ordinary fresh layer write bases as private
selectors for removal/reassociation under a separate lifecycle condition. A
historical creation reference is not a write grant; obtaining and using a fresh
basis still requires current per-layer rights. Native registry and association
permissions remain independent. No public wire/Rust identity format is selected.

## Conditional preservation arguments

Selector fidelity follows from bounded exact indices, distinct actual incarnations,
owner/context/profile-bound original handles and repeated current resolution.
Native lowering retains complete conditions and authority checks; selection cannot
manufacture registry rights. All selected footprints and complete pure validation
precede stateful permission-loss observation, preserving unrelated valid conditions
on malformed or stale input. Shared publication either installs its validated
candidate or retains the prior root on the selected refusal/fault traces.

Finite bounded input vectors and the existing closed native dispatch give bounded
traversal; no user callback, recursion, await or I/O is added. This is a conditional
construction argument, not a new machine-checked termination theorem. Occupancy
and lifetime issuance remain governed by existing nonrefunding pools. Forgetting
the original result and retiring the later basis are deliberately different acts.

## Instrumentation and remaining gates

INS-01/02/03/08/09/12/13 observe capture, validation, changed/no-op publication,
refusal/fault and protected discharge. Keep queue/service, result reservations,
basis occupancy and issuance separate. Use bounded codes, never handles, native
identities, raw paths, values or source in ordinary telemetry. Identity substitution,
stale conditions, permission loss, false authority promotion and leaked holds are
STRIDE/LINDDUN and STPA/FMEA scenarios at these existing interfaces.

These checks do not prove public token codecs, all lifecycle consumers, provider
truth, hostile runtime containment, production package independence, physical heap
peaks, concurrent installation, crash behavior or independent Cleanroom assurance.
The existing 295 SMT conditions/fourteen manifests retain their original scope.
