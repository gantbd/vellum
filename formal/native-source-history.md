## One root consumer and separate producer lifetimes

A changed source association archives its exact prior binding and source baseline.
Native history release removes that document's explicit bindingHistory array only
after current authority and independent history/snapshot/read/write/provider
discharge facts. It does not erase user edit history, source/annotation content,
current binding/baseline, annotation binding history, views or workspace membership.
It does not release a resource key, writer reservation, worker slot, artifact or
producer evidence. Unknown or malformed rows cannot be silently coalesced to empty.
Supported shape checks identify the existing retention representation; they do not
prove a receipt, provider fact or discharge assertion true.

The exact private input contains document and expectedBinding. A live owner with
that current binding and explicit bounded history is required. An empty array is
unchanged, including at publication-counter exhaustion. Nonempty success increments
publication once and changes only that array to empty. No binding/source/annotation
generation advances. An old expected binding is stale even when history is empty.
Content-read and external-effect grants are not release-control authority and are
not needed by this no-I/O control.

## Native execution and conditional arguments

The actual source-save factory derives the normalized candidate from the actual
native root. The fourth private destination transition kind uses the existing
lifecycle/membership/bindings profiles and private exact-domain/before-root
certificate. It rechecks twenty-four exact-true facts, independently reconstructs
the allowed delta and validates current ordinary-pair evidence at native installation.
Actual root caps and existing baseline-promise floors apply even to a root shrink:
smaller retained bytes do not create a publication-counter unit. Source journals
carry under unchanged source tuples; the frozen root installs with consumed token
identity. A normalized candidate does not alter actual native ownership or pins.

Assuming truthful current authorization/discharge/coverage facts, exact root identity
and closed-delta reconstruction give the serialized frame argument. Every peer
and unrelated authored/history field is unchanged. Intervening publication invalidates
prepared work; foreign, copied, discarded or consumed certificates cannot be reused.
The closed branch performs finite scans over bounded root inventories, with no
callback, suspension, provider I/O or retry path. These are conditional authored
arguments about this reference, not categorical completeness, hostile package
isolation or production concurrent/crash atomicity.

## Actual native source producer consumers

Native source-write retirement uses its actual root, not a replacement supplied by
a caller. It checks supported source baseline/binding/history positions across live
and retained-disposed owners, and the current shared writer's queued baseline
consumers. A known peer acknowledged baseline or write-origin reference still pins
the producer after its original owner's history is released. Unknown source consumer
shape is not evidence of absence. The check does not interpret arbitrary prose,
annotation bodies or presentation strings as executable producer references.

A separately provenance-released owner with null active/retained source bindings
has discharged its semantic pins under the existing lifecycle contract; remaining
cold data is not automatically a live consumer. For the producer's own current
binding, keep existing actual baseline serial election: a newer qualified producer
may supersede the old write while preserving the association's birth qualifier.
That qualifier alone is not an immortal self-pin. Unresolved/conflicting effects,
quiescence, independent retention/delivery facts and other consumers still govern
actual retirement. Cancelling a queued dependent prevents future dispatch but does
not refund its separately retained ticket/artifact or recycle issuance.

This is a conservative check of known positions in the supported root/current-writer
profile. It does not prove all external consumers, imported provenance or complete
host coordination. The queued-consumer negative control deliberately admits an
existing normalized historical capture to the actual writer; it is not proof of
completed native ordinary-source admission. Peer-reference controls inject typed
or unknown host metadata to challenge cleanup; they do not authorize cross-owner
baseline adoption. All source-read producer retirement remains a separate gate.
