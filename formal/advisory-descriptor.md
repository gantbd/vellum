# Existing proposal validation declaration

F10 already supplies a synchronous advisory query for the native compound-plan
profile. Its fixed declaration describes that query, not a command, reservation,
general semantic analyzer or permission to execute a future edit. The native
request/basis guards and reply profile share an immutable declaration; obtaining
the declaration neither invokes the query nor acquires authority.

The input schema covers only the existing contract, operation and object-valued
plan. Nested compound plans, original domain/context, exact current root/request
observation basis, grants, dependencies and actual resource limits remain native
checks. The closed result schema describes unavailable, or advice with the native
profile and a strict Boolean checksSatisfied value. Negative advice is not an
execution failure; unavailable is not a fabricated negative verdict. Positive
advice creates no invocation, journal receipt, publication, effect or held capacity.

Both typed and dynamic native paths supply actual positive and negative examples.
Fifty-seven JSON Schema 2020-12 cases include 34 syntax refusals. Ten recognition
refusals and six schema-valid native refusals distinguish metadata equality from
native meaning/authority. Five controls retain the declaration, immutable data,
current root/reported usage and exact outcome distinctions. Seventeen pure
descriptor mutations fail semantic assertions; construction/tool failures do not
count. The unchanged native corpus separately retains 2,048 query gate cases,
128 route cases, 42 stages/84 native queries, twelve controls and thirteen native
mutations. These corpora have different scopes and are not added into one count.

The standalone declaration corpus does not exercise discovery registration.
Discovery /12 integration is covered separately in advisory-discovery.md. This
separation does not mean the integrated native profile is absent. The declaration
is not a raw-ingress decoder, arbitrary JavaScript isolation boundary, general
schema evaluator, transport codec or proof of every native job/provider's meaning.
No command-result retrieval choice is selected.

IF-01/02, PATH-02 and INS-01/03/08/09/12/13 retain bounded metadata/advice/current
release/fault/cleanup distinctions without authored plans, identities, field names
or payload-derived labels as telemetry. No instrumentation pathway is installed.
Full frozen qualification and endpoint adoption remain required; complete public
products, actual host policy, physical/operational and independent gates remain.
