## Ordinary admission

The trusted native coordinator obtains the actual healthy root. Its private
ordinary-admit input is exactly the existing source-save/1 request, not a caller
supplied root or serialized artifact. The factory reuses the normalized request,
registration, unique owner, current source/settings/binding, retained baseline,
condition and writer-budget checks. It requires the existing exact profile with
lifecycle, membership and bindings sections and twenty strict current facts: the
source export admission facts except destinationAllowed. An ordinary save uses
its current ordinary binding; it does not create an export intent or require a
new destination grant. The current complete pair and resolved-distinction policy
still apply.

A loaded anchor must come from the actual native read registry in this domain
and its actual paired writer. The private witness retains actual producer
references and bounded copies of its activation, context, transcript and terminal
witness. Final commit rechecks that retained producer, its uncontested evidence
and unchanged provenance. An acknowledged anchor must come from an actual native
task in this writer and domain, with exact captured context and codec bytes.
Legacy, foreign and missing producers are not silently adopted.

The existing source codec prepares immutable current source/serialization bytes
and reserves its shared source-preparation capacity without issuing an artifact
or spending a lifetime origin. The closed certificate binds actual domain,
before-root pointer, writer, profile, original capture and private preparation.
Final profile/frame/pair/fact/producer/writer/codec/native-floor checks precede
one serialized artifact/ticket/origin commit. The root pointer and publication
counter are unchanged, no export reservation is added, and reservationReleased
starts true. Refusal discards the preparation without spending issuance. The
trusted preparationReserved premise covers preparation/snapshot resources;
logical bounds are not a proof of actual allocator, stack or physical ownership.

## Execution and baseline publication

Native tasks dispatch only against their actual healthy domain root. Existing
FIFO, per-key unresolved-effect barriers, pinned/own-chain conditions, exact
current binding/registration/pair and matching attested probe remain. Native probe,
payload-release, evidence-kind and causal-progression grants require true, not
truthy substitutes. Later edits do not recapture a queued payload. Genuine late
evidence remains attributable after stop or a native-owner fault; fault does not
authorize new work or root publication.

The private baseline control has exactly {document}. It selects no caller-supplied
bytes, task, baseline or replacement root. Sixteen strict current facts combine
the existing baseline-publication facts with owner/preparation/current-pair facts.
Select the newest actual qualified dispatch for the exact current context under
the existing normalized election. A legacy winner is a refusal, not permission
to skip it and publish an older native candidate. A current acknowledged baseline
also needs its retained native producer. Supported loaded/null baselines can be
replaced by independently qualified native writes without claiming old read truth.

The final validator independently re-elects from actual current writer tasks and
registration/ownership context. It reconstructs the full baseline from the
selected task's immutable codec artifact and current qualified knowledge. A newer
eligible write, contradictory evidence, missing artifact or stale root invalidates
preparation. Publication changes only the named sourceBaseline and one safe root
publication increment. Equal metadata is unchanged; all authored state, other
baselines, identity/relationship/history metadata and source journals survive.

Full written application plus the captured requested acknowledgment qualifies a
historical baseline. Task stop, safe effect disposition and worker quiescence are
different facts, not additional baseline prerequisites. They still govern future
dispatch and retirement. A failed synchronization retains written knowledge but
does not satisfy a synchronized request. A tokenless acknowledgment can establish
historical bytes, not another version-conditioned save; compatible token learning
can be explicitly published without fabricating a version.

Current declared profile limits, actual native root limits and existing annotation
baseline promises all apply. Admission makes no new promise of future source-
baseline root/counter capacity. An external write can therefore be acknowledged
while local baseline publication refuses; retain its task, artifact and evidence.
This is not atomic external I/O plus local metadata publication, crash recovery,
or a new automatic retry/rollback policy.

Native producer retirement uses the actual root and existing current, retained,
peer and queued-consumer fences. Genuine consumer release and independent
effect/quiescence/retention/drain facts precede artifact/task retirement. The
private native codec association is then dropped; issued origins are not refunded.

## Conditional preservation arguments

Assume the existing normalized codec, source-read, source-save, binding-pair and
root-owner contracts; bounded plain normalized objects; serialized trusted
composition without reentrant provider callbacks; and truthful current host
identity, authorization, coverage, preparation and retention facts.

1. Admission refusal preserves root, writer tasks/used origins and issued artifacts.
   Preparation changes only its existing codec hold. Either final validation fails
   and discard removes that hold, or the single synchronous commit consumes it
   and installs exactly one artifact, task and spent origin. No root field changes.
2. Baseline attribution follows actual native task ownership, qualification and
   exact immutable artifact reconstruction. Re-election at commit excludes an
   older prepared choice when a newer eligible task exists. The complete delta
   reconstruction permits only sourceBaseline and its publication advance; the
   native owner carries existing source journals and applies actual promise floors.
3. Evidence does not regain lost certainty. Native intake imports the existing
   compatible refinement/contradiction rules and strict independent attestations.
   Stop and quiescence cannot manufacture acknowledgment or discharge uncertainty.
   The capped contradiction store is not arbitrary-union lattice closure.
4. The private control vocabulary is closed. Each invocation terminates through
   bounded scans, sorts, copies and schema checks over existing finite profiles.
   A pending certificate is consumed by commit or discard. This is per-call
   termination, not a theorem that an indefinitely running editor or external
   provider halts, nor whole-engine categorical or bounded-lattice completeness.

These are authored conditional construction/trace arguments, not proof-assistant
checked induction, complete temporal-module refinement or independent certification.

## Executable evidence

native-source-save-checks.mjs exercises 42 ordinary native admissions and baseline
publications across the existing fourteen annotation variants and capture/undo/redo
stages. It checks 1,048,576 admission and 65,536 baseline fact vectors, 108 strict-
value refusals and thirty controls. These include mixed source bytes, native
SaveAs-to-ordinary continuation with annotations, old captures after edits,
token refinement, late read/write conflicts, election races, private certificate
ownership, native/profile/promise limits, producer retirement, fault supervision
and framing against unrelated source/body/output changes.

Twenty-seven semantic mutants are rejected after a passing coherently rewired
multimodule baseline. Compound mutants disable redundant guards together where
one guard alone is masked by another; this does not claim every individual guard
is independently necessary. Syntax/import/TypeErrors do not count as kills.
The existing 234 SMT conditions/fourteen manifests remain unchanged.
