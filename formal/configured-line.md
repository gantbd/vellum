## Explicit configuration binding

The typed or dynamic envelope carries the same bounded request. Its configuration
field names an exact target and a closed key map: unit/tabWidth for indent-lines
and outdent-lines, delimiter/autoIndent for insert-newline. Values name registered
source-domain keys; their spelling does not establish applicability. The current
trusted authority record binds the complete execution context, document, view,
action, target and key map, with separate exact-true read/use grants. The request
cannot grant itself authority. No active window, focused document, path search or
universal setting-key catalog is inferred.

Preparation reads the actual native configuration, resolves typed values and
lowers through the existing line helper. It captures schema, restriction and
association epochs plus the selected target's source-domain generation. A charged
retained interpretation lease belongs to the same owner/domain/invocation ticket.
The normalized plan and inner intent must fit both settings and parent invocation
budgets before lease issuance. Retrying preparation never refreshes dependencies.
Settings mutation and configured editing cannot occupy the same invocation slot.

At publication, exact current producer facts, authority, retained interpretation,
captured epochs and actual values are checked again. Host-supplied lineSettings
cannot replace resolved values. Configuration ABA and selection-only staleness
refuse; disjoint target/domain/document progress is preserved. A valid no-op still
checks its assumptions but needs no unused source version. The existing source,
annotation, all-attached-view and native history contract remains in force.

Cancellation and faults preserve the interpretation lease until protected
retirement establishes retention release and delivery drain. Retirement releases
only that lease; lifetime issuance is not refunded and a closed pool cannot reopen.
Legacy explicit-prefix-line-edit/1 remains valid without a configuration service.

## Precedent and scoped evidence

[CodeMirror's immutable state](https://github.com/codemirror/state/blob/main/src/state.ts)
provides state-owned facet lookup for tab size and line separation.
[Its facet readers and declared dependencies](https://github.com/codemirror/state/blob/main/src/facet.ts)
separate read access from definition and require computed values to declare their
inputs. Vellum adopts the explicit semantic-input/dependency pattern, not JavaScript
callbacks, their normalization defaults or their permission model.

Run configured-line-checks.mjs with the pinned ICU4J reference available. The
checker preserves sixteen legacy editing controls and adds 28 controls, seventeen
malformed, sixteen budget, ten argument and ninety non-Boolean/current-fact cases.
Eleven coherent source mutations are assertion-killed after an unchanged baseline.
These include ignored configuration epochs, supplier-value substitution, truthy
grants, substituted authority/context, leaked leases, unsupported tuples and
same-slot plan substitution. Actual common cancellation covers 24 forms/twelve
kinds: 384 gate/192 context cases, 48 races and 6,216 traces/17,424 edges.

This is executable reference composition, not a new universal solver theorem.
The existing conditional publication, no-op and bounded-retention laws retain
their assumptions; they alone do not prove this source implementation. Complete
consumer discovery, actual applicability/policy truth, public key catalogs and
codecs, Rust/native packaging and physical/concurrent/crash/independent refinement
remain separate gates.
