# Settings query argument capture

The existing F07 reader accepts effective-configuration, permitted-origin and
capabilities through typed and dynamic engine routes. Fixed immutable declarations
now supply the reader's actual field lists and the bounded argument normalizer.
No new operation, acquisition endpoint, UI preference or transport is selected.

## Canonical meaning and opaque roles

The normalizer checks closed data-only envelopes, routing tuples, argument fields,
nonempty profile/key strings and the existing eight-field authority scope. It
captures ordinary data and limits as owned immutable values. Context and target
are separate original opaque references: canonical records contain null shadows,
and reconstruction restores each original role without cloning, traversing or
authenticating it. Typed and dynamic routes have the same semantic record while
reconstruction preserves the selected route.

Unknown keys and unsupported profiles remain unmodified for the actual native
reader to refuse. Normalization cannot turn a context or target lookalike, origin
selector, permitted declaration or advisory answer into authority. Actual owner
scope/currentness, captured projection, visible values/origins/declarations,
absorbing observed loss and retained lifetime remain controlled by §22.2.1.1.
Malformed requests cannot invalidate another context. Protected cut disposal is
separate from query success; a refused query may leave a prepared cut to discharge.

## Bounds and scoped evidence

Independent logical ceilings apply to complete envelope shadow, authority scope,
captured semantic record and declared input limits. UTF-8 JSON bytes, input nodes,
depth and the outer maximum are checked separately. Metadata classification cost
is explicit. Opaque internals are excluded from traversal, not claimed physically
free. This argument-only slice does not establish actual-parent decoder charging,
raw ingress containment, result codecs, public discovery or physical/global bounds.

Nine controls cover seven operation/key combinations across both routes, fourteen
native products, 92 malformed-envelope/domain refusals, six opaque-role cases and
36 below/at/above boundary cases. They include accessor/symbol/hidden-field and
foreign-prototype refusal, independent authority field omissions, canonical
non-aliasing and actual absorbing native loss. Twenty-six coherent copied-graph
mutations separately challenge identity, canonical meaning, limits and producer
reconstruction. Construction and incidental process/syntax failures do not count
as semantic evidence. The existing native reader retains all 22 mutation challenges.

IF-01/02, PATH-02 and INS-01/03/05/08/12/13 retain argument capture/refusal, native
release, captured/current disclosure, invalidation and protected cleanup
distinctions. Existing MELT/golden/RED/USE and STRIDE/LINDDUN/privacy/hazard coverage
applies without raw handles, targets, setting keys/values or permission packets as
ordinary telemetry labels. No runtime signal or numeric default is added.

Full frozen qualification and endpoint reconciliation remain adoption gates.
Actual-parent decoded dispatch, complete result/discovery products, host policy,
operational measurements and independent refinement remain separate obligations.
