# Native history query discovery

Explicit discovery /7 adds the existing F04 query descriptor after /6's seven
rows. The three operations and their native execution are unchanged. Fixed
declarations from the existing argument/result guards supply three input and
three result JSON Schema 2020-12 schemas. Exact recognition admits these
declarations, not arbitrary schemas, callbacks or reference loaders.

## Structure and authority

Inputs describe outer structure; results describe native value structure. Closed
fields retain direction, legal null groups, nonempty labels, blocker rows and
success/unavailable branches. The object-valued context is a JSON shadow of the
native handle, not a transport encoding. Private lower-level string contexts are
not this public native product.

Actual owners still check original context identity, current basis/grants and
retained lifetime, captured aliases/detail ceilings, eligibility, ordering and
copied-value integrity. A forged context shadow, fabricated eligible value or
schema-valid reordered blocker list supplies none of that authority. Query advice
cannot authorize reversal. UTF-8 validity and actual alias coverage remain native
checks rather than consequences of a standard string schema.

## Compatibility and bounded release

Profiles /1–/6 retain their products. Canonical fingerprints in
history-discovery-checks.mjs were captured from the qualified older baseline;
they sort object keys recursively but preserve array/descriptor order. They test
semantic JSON compatibility, not wire-byte ordering. The /7 reader retains older
read input/result recognition and private builtin origin, without allowing an
equal generic declaration to borrow that origin.

Captured disclosure cannot expand. Recognized withdrawal remains absorbing;
foreign scope, unknown profile and malformed selectors cannot poison a valid
context. Publication exclusion, protected retirement and spent issuance remain
binding. Ten independent envelope dimensions cover entries, variants, row bytes,
metadata bytes/nodes/depth, packet bytes and each of the F02/F03/F04 reply sizes.
Metadata depth 22 is necessary for these inline descriptors. Explicit test depth
32 is not a product default, and refusal does not disable older profiles.

## Instrumentation and threat coverage

IF-01/02 and PATH-02 retain discovery and actual-owner query edges. INS-01/03/05/
08/12/13 separate descriptor admission/release, captured disclosure, current
withdrawal, envelope refusal, native validation and invariant fault. MELT/golden/
RED track these bounded stage/outcome populations, latency, errors and throughput;
USE tracks declared occupancy, saturation and refusal at their actual owners.
No new runtime signal or numeric threshold follows from metadata alone.

STRIDE challenges owner/selector substitution, metadata tampering, callback
execution, disclosure escalation and resource denial. LINDDUN/privacy/hazard
coverage challenges history/scope linkage and capacity inference. Do not emit
opaque handles, history aliases, authored content or raw authority packets as
metric labels or diagnostic payloads. Discovery does not observe actual frontier
eligibility merely by describing its result shape.

## Scoped evidence

The product corpus has 354 standard-validator cases, 24 native products (22
successes and two expected unavailable-detail products), 39 recognition denials,
nine schema-valid runtime refusals, three alias non-authority cases and two
semantic/non-public-value distinctions under seven controls. The discovery corpus
has sixteen controls, 51 schema denials and four loss cases. Thirty boundary cases
exercise the ten dimensions above without selecting numeric product defaults.

Three banks of seventeen mutations each execute the complete product/discovery/
boundary corpus against coherent captured graphs. Construction targets must occur
exactly once; syntax, process, tool and protocol failures do not count as semantic
detections. The old unknown-profile probe moves from /7 to /8 because /7 is now
recognized. Two legacy builtin mutation seams target their original branch
explicitly, with exact-one assertions, preserving their original challenges.

Selected substrate probes intercept 143 callable functions after import and
fixture construction. Sixteen discovery controls consume 24 preconstructed
discovery fixtures and two history fixtures, with zero baseline host calls and
three detected fixed read/rename/process injections. This tests selected execution,
not import containment, static production dependencies or all host APIs.

Full frozen verification and endpoint reconciliation remain adoption gates.
Complete public products, global/physical accounting, actual host/provider truth,
concurrency/crash refinement, measurements and independent assurance remain
separate obligations. No categorical or unbounded completeness follows from these
finite checks.
