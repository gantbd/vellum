# Resource catalog query results and faults

Existing F07 resource-catalog list and inspect replies now have closed native
result validation and retained fault handling. Page, registration and unavailable
remain the only query statuses. Acquisition results, charged decoded entry and
complete discovery products remain separate obligations. No operation, transport,
UI policy, provider callback or filesystem procedure is added.

## Structure and captured meaning

Replies bind the original context and captured-permitted coverage. Pages contain
dense, bounded entries with distinct original references and read/write table
labels, plus null or an original continuation. Inspection binds the original
requested entry and optionally discloses its captured descriptor. Unavailable
contains no reason, private stamp or other field.

Descriptor fields come from shared immutable native projection declarations.
Source reads retain the existing profile, Boolean atomic-read flag and LF/CRLF/CR
line-break vocabulary; annotation reads retain their existing profile and Boolean
flag. Write descriptors retain a nonempty valid string procedure and their
existing Boolean capability fields. The line-break vocabulary is shared with the
actual catalog validator. No new procedure-name enumeration is invented.

Shape is not native registration truth. Inspection separately compares the whole
disclosed table/descriptor with its retained permitted row. Page entries bind the
exact staged entry map, captured table, index, context and selector kind. The
continuation binds its original reference, context, next start and page limit.
Copied handles, same-shaped selectors, reordered tables and shaped but different
capability values cannot stand in for captured meaning or current permission.

## Installation and retained fault handling

Validate page meaning before installing staged selectors, and inspect meaning
before classifying reply pressure. A valid oversized reply returns unavailable
without invalidating the context or partially installing selectors. An internally
malformed oversized reply is an invariant fault, not ordinary capacity refusal.
Revalidate at the outer native release boundary against actual installed maps.

An unexpected bound native query failure invalidates only the affected context,
clears its delivery data and selector bindings, and returns unavailable. Keep its
slot, registry reservation and spent lifetime issuance. Do not fault the execution
domain, mutate the authored root, cancel a producer or invalidate a healthy sibling.
An early failure may leave its preparation unconsumed; dispose of that cut
separately. Owner stop, retention release and delivery drain still precede context
and whole-registry retirement.

Before installation, unexposed staged aliases do not spend lifetime issuance. If
installation already committed, a late refusal does not roll it back: the affected
context loses delivery eligibility, but its newly spent issuance survives until
the native issuer lifetime ends. Context retirement does not refund that issuance
or the registry's fixed reservation. The registry charge is the existing declared
logical budget, not a newly established shared-parent or physical reservation.

## Conditional progress and instrumentation

For a fixed captured row count n, a positive limit L and an accepted continuation
at start s, the next boundary is min(s+L,n). A nonterminal successful page therefore
strictly decreases n−s. Following each returned continuation reaches the end in
finitely many successful pages. Reissuing an old query, refusing a call or changing
host facts is not a claim of client fairness or eventual delivery. Each query uses
the existing bounded native synchronous path; this argument is not categorical
completeness, a bounded-lattice proof or a physical execution-time guarantee.

IF-01/02, PATH-02 and INS-01/03/05/07/08/09/12/13 distinguish frame/binding
validation, ordinary refusal, selector installation, release, first invalidation,
retained obligations and protected discharge. MELT/golden/RED track distinct
pathway populations and latency/error classes; USE tracks declared usage and
saturation. STRIDE/LINDDUN/privacy/hazard coverage challenges selector spoofing,
descriptor tampering, premature refund, sibling interference and registry linkage.
Raw replies, handles, provider/resource identities, descriptor values and policy
facts must not be ordinary telemetry labels or fault payloads. No signal threshold
or numeric default is selected.

## Scoped evidence and remaining obligations

Six controls cover 73 native products, 66 malformed-result refusals and sixteen
page-binding cases, including withheld descriptors, all existing descriptor forms
and transient reply pressure. Thirteen fixed stages yield eighty fault cases over
fourteen ten-case rows including the baseline. Ten early cuts require separate
disposal; twelve late page cases preserve newly spent issuance. The corpus checks
sibling health, unchanged authored/parent state, retained context/reservation and
protected context/registry discharge.

Three mutation banks detect 33 changes against the complete shape/fault corpus.
Construction, syntax and process/tool failures do not count as semantic detection.
Selected post-import substrate probes wrap 143 filesystem/process callables and
execute six controls using eight preconstructed fixtures, with no observed
baseline substrate calls and three detected read/rename/process injections. They
do not prove import isolation or general host containment.

The earlier native reader and registration suites retain all forty and thirty
mutation controls; the 27 argument mutations also remain checked. Seventy selected
nonfault JSON products, roots and private/parent ledgers match the prior candidate;
this is not an opaque-identity, all-profile, crash or independent equivalence proof.
Full frozen qualification and endpoint reconciliation remain adoption gates.
Acquisition-result handling, actual-owner gateway accounting, complete discovery,
other families, operational measurements and independent assurance remain open.
