## Declaration and identity ownership

[annotation-editing.mjs](annotation-editing.mjs) and
[history-reversal.mjs](history-reversal.mjs) export parameter-free, deeply frozen
descriptors. They read the same private catalogs used by their request guards.
The annotation descriptor includes common and variant fields; history includes
its declared common field types. Outcomes, named profile constraints and
descriptive cancellation requirements remain data, not executable predicates or
live enablement. These names are not a complete wire schema or frozen Rust ABI.

[native-discovery.mjs](native-discovery.mjs) imports these known producers directly.
The fixed source checks its variants against the engine-only inventory and binds
internal command identities to the reader's actual authority and engine. The
family labels and internal tuple spelling are not assigned stable public IDs.
No caller registry, callback factory, owner label, keymap or input mode selects
the source. Owner inspection returns independent bounded rows for deriving
visibility facts; ordinary recipients still use opaque discovery references.

[Neovim's API metadata documentation](https://raw.githubusercontent.com/neovim/neovim/master/runtime/doc/api.txt)
describes dispatch and metadata generated from API headers. The adopted precedent
is a shared declaration origin, not Neovim's transport, evolution rules, runtime
or security properties.

## Origin preservation and current release

The built-in preparation path discharges only accepted-source and schema-description
origin for these declarations. All existing authority, interpretation, complete
visibility/order, resource and target/advice premises remain required. It builds
fresh bounded rows internally before using the existing single-use root/scope-bound
packet path. It neither executes nor registers a handler.

A private origin marker follows the packet into its retained context. Every fresh
query cut must match that origin before selector staging. Therefore an arbitrarily
attested generic cut cannot refresh a built-in context even when its visible bytes
are identical; a built-in cut cannot silently upgrade a generic context either.
The generic path retains its explicit external producer premise. The marker is
included in the built-in capture-byte bound and is not a released envelope field.

Root-stale preparations refuse. An unrelated source edit may preserve unchanged
permitted metadata under a fresh current cut. Current disclosure narrowing still
refuses the old richer envelope; later grants cannot expand its ceiling. Stop,
retirement, spent issuance and no-reopen rules remain the existing reader's rules.
Origin rejection reports unavailable, not private source details.

## Evidence and limits

[builtin-discovery-checks.mjs](builtin-discovery-checks.mjs) independently lists
the six operation field sets and compares them to actual preparation: six valid
products, 49 required-field omissions, six extra-UI-field refusals and six
descriptors. Eight schema/variant facet cases and thirteen controls cover source
copy isolation, identity/scope, current native frames, generic lookalike refusal
in both directions, finite source/packet limits, exact origin capture charges,
stale-root refusal, unchanged metadata after edits, protected retirement and
absence of implicit enablement. Nine semantic mutants must fail assertions after
an unchanged coherent module-graph baseline; load/syntax errors do not count.

This is finite reference evidence for declaration origin and selected field
correspondence. Full value-type/codec constraints, all-family installed handler
correspondence, mutable registry activation, actual visibility/policy/advisory
truth, host behavior, physical accounting, concurrency/crash refinement and
independent assurance remain open. No new solver theorem or global categorical
closure follows. Existing 262 SMT conditions across fourteen manifests are unchanged.

## Instrumentation

CMP-02 owns accepted engine contract interpretation; CMP-15 retains binding/input
policy. Reuse INS-09 for source preparation/interpretation and INS-01/03 for query
admission/current release, with INS-08/12/13 for bounds, disclosure and lifecycle.
Separate preparation attempts, context acquisition, release refusal and successful
descriptor delivery. Origin is a bounded internal classification, not a permission
or proof label. Raw command identities, metadata, source text and recipient/context
references stay out of ordinary metric labels. MELT/golden/RED/USE and STRIDE/LINDDUN
remain attributed to these existing interfaces; installed hooks and measurements
are separate evidence gates.
