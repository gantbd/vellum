## Closed values and native authority

Execution carries pending/terminal phase and its independently staged observation
token. Only ordinary terminal status can include a disclosed outcome; minimal
control cannot. Retained-outcome has a separate outcome branch. Waiting retains
the exact staged wait object. Observed wraps ordinary execution, not a recursive
message language. Unavailable does not infer producer failure or nonapplication.

Nested outcome validation follows the existing native projector's exact fields,
finite vocabularies, reason ordering and dense array bounds: at most two reasons,
two participants and one recovery item. Count equals the disclosed participant
list, or withheld details use empty participants and null count/correlation.
These are existing selected native reference labels, not newly adopted public
reason codes, ranking or retry instructions. Valid shape proves neither policy
truth, alias authenticity, actual effect evidence nor authority to recover/retry.

Independent malformed-value cases challenge foreign/copied tokens, wrong
operations/phases, minimal-control outcome leakage, extra/missing fields, nested
vocabulary/order/count errors and accessors. Opaque internals are not traversed.
Schema-like shape alone can accept a fabricated identity or plausible recovery
value that the actual owner never issued or authorized.
