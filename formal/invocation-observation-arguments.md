# Exact invocation observation arguments

Section 23.1.7 now supplies selected actual shared dispatch using this argument
meaning and an explicitly prepaid decoder profile; see observation-decoder.md.
Argument-only evidence below does not itself establish that integration or
remaining public/operational/independent products.

The existing F06 native observation guard supplies four immutable input forms:
status, retained-outcome, minimal-control-status and bounded-observation-wait.
Typed and dynamic argument capture derives from those same forms and preserves
their existing native meaning. This is not a public acquisition fallback or a
transport protocol.

## Canonical meaning and opaque roles

Capture exact envelopes and operation tuples, requiring the F06 family, supported
version and agreement between variant and operation. Capture the existing
invocation reference label and profile as nonempty UTF-8 text. Preserve the
original object-valued observation context; wait requests also preserve the
original ordinary observation reference and positive safe-integer logical budget.
Neither opaque object is inspected, serialized or cloned.

The authority frame is the original invocation's seven fields: authority, engine,
recipient, purpose, destination, profile and continuity. It does not acquire the
separate history projection's policy field. The frozen canonical record contains
captured ordinary arguments, authority frame, limits and explicit opaque roles;
context/after slots are null shadows. Original opaque objects remain separate.
Typed/dynamic route syntax is not canonical meaning. Semantic equality compares
both captured data and original opaque identities.

Copy each ordinary frame under independent byte/node/depth bounds, with request
bytes clamped to the caller's actual-owner maximum. Limit classification itself
requires exactly the three finite limit fields. Reject non-data properties,
accessors, invalid UTF-8, malformed tuples and unsafe numbers. These reflection
and copy rules do not establish proxy/native-code containment or preallocation
bounds. The helper does not itself reserve against an actual owner's budget.

## Native authority and observation lifetime

Reconstruction restores original context/after objects. Native lookup still owns
invocation/context/profile equality, current grants, captured/original/current
policy ceilings, retained outcome availability and ordinary/protected reference
roles. A well-shaped foreign context, foreign invocation label or minimal-control
after-reference cannot borrow ordinary wait authority. Budget shape does not
establish the owner's maximum steps, capacity or host clock/service truth.

Reads and waits never run, stop or retire the producer. Revocation remains
absorbing when the actual native owner recognizes it. Wait expiry/drain and
producer completion/retirement remain separate. Actual-owner bounded decoder
charging and integrated dispatch are follow-on obligations, not consequences of
pure normalization.
