# Native observation discovery

Explicit discovery /8 appends the existing four F06 observation operations after
/7's eight rows. Fixed declarations shared with the native argument/result guards
supply four input schemas, four operation-reply schemas and one separately scoped
private wait-continuation schema, using JSON Schema 2020-12. Exact recognition
accepts these declarations, not arbitrary schemas, loaders or executable callbacks.

## Structure and authority

A wait-start reply is waiting or unavailable. Its private continuation may also
be observed or observation-ended; observed wraps an ordinary execution result.
This distinction does not introduce public wait acquisition, a public event
transport, a clock source or a network protocol. Minimal control remains thin and
independent of ordinary readiness and issuance. Ordinary status may disclose a
rich outcome only in terminal phase.

Native outcome schemas retain the existing nine closed fields, finite private
vocabularies, canonical bounded reasons, exact disclosed participant counts and
withheld details. Those private labels do not select public explanation codes or
grant retry authority. Opaque object shadows do not authenticate contexts,
invocations, observations, wait references or discovery selectors. Standard string
shape does not establish UTF-8 validity. Positive integer budget shape does not
establish actual clock, budget or capacity eligibility.

Actual owner context, original reference identities, current policy/release,
captured disclosure ceilings, native result projection and retained lifetime
remain authoritative. Describing protected decoding does not enable it: the
explicit bootstrap and prepaid admission profile in §23.1.7 remain necessary.
Advisory enablement cannot control the producer or authorize observation.

## Compatibility and bounded release

Profiles /1–/7 retain their semantic JSON products. Pinned canonical fingerprints
from audited specification 0.172 sort object keys while preserving row, variant
and array order; they do not assert byte-order or wire compatibility. Profile /8
retains older read and history schema recognition and private builtin origin.
Equal generic metadata cannot borrow that origin.

Captured disclosure cannot expand; recognized withdrawal is absorbing. Foreign
scope, unknown profiles and malformed selectors cannot poison an existing valid
context. Publication exclusion, protected retirement and spent issuance remain
binding. Thirty-three below/at/above cases cover eleven envelope dimensions:
entries, variants, row bytes, metadata bytes/nodes/depth, packet bytes and each
F02/F03/F04/F06 descriptor reply size. Measured descriptor depth is 22. The explicit
fixture depth 64 does not change product defaults; insufficient capacity may
refuse /8 while leaving an older profile usable.

## Instrumentation and threats

IF-01/02, PATH-02 and INS-01/03/05/08/12/13 distinguish descriptor preparation,
admission, release, schema ceiling, withdrawal, envelope refusal, native validation
and protected discharge. Existing MELT/golden/RED populations distinguish their
latency, throughput and errors; USE distinguishes owned occupancy, saturation and
refusal. Metadata alone supplies no measured latency, physical allocation bound,
new signal or numeric threshold.

STRIDE covers scope/selector substitution, metadata tampering, executable
declarations, disclosure expansion and resource denial. LINDDUN/privacy/hazard
coverage includes invocation linkage, private outcome/recovery disclosure and
capacity inference. Do not place handles, invocation labels, authored content,
reason payloads, policy packets or clock details in ordinary telemetry labels.
Discovery does not observe producer truth merely by describing an outcome.

## Scoped evidence

The standard validator checks 1,038 cases including 37 native operation/transition
products, 708 projector products, malformed domains and branch distinctions.
Twenty-five recognition denials, eight schema-valid runtime refusals, one alias
non-authority case and two semantic/non-public distinctions separate shape from
authority. Fourteen discovery controls include 69 schema denials, four loss cases
and thirteen native role refusals.

Four mutation banks challenge 54 descriptor, recognition, compatibility, disclosure,
capacity and lifetime changes against the complete product/discovery/boundary
corpus. Construction targets occur exactly once; syntax, process, tool and protocol
failures do not count as semantic detections. An explicit page assertion detects
schema-ceiling expansion before any result dereference. Older unknown-profile
probes now use /9; their refusal obligations are preserved.

Selected post-import probes wrap 143 filesystem/process callables. Eighteen
preconstructed discovery fixtures and two observer fixtures execute fourteen
controls without baseline host calls and detect three fixed read/rename/process
injections. This is selected execution evidence, not import or all-host containment.

Full frozen qualification and endpoint reconciliation remain adoption gates.
Complete all-family public products, global/physical accounting, host/provider
truth, concurrency/crash refinement, operational measurements and independent
assurance remain separate. Finite checks imply neither categorical nor unbounded
completeness.
