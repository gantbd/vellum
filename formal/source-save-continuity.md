## Original and derived conditions

Admission retains the original source/settings/artifact, binding and full provider
registration, original baseline and condition. A pinned condition never advances.
The explicit own-chain policy permits a separately recorded derived condition;
it does not authorize replacing the payload, changing provider/procedure/binding,
refreshing arbitrary tokens or relaxing a pinned request.

causalReceipts and nonReuseTokens are independent declared capabilities, separate
from conditionalWrite and syncSupported. Non-reuse is within the exact declared
identity/validity epoch, not an inference from validator spelling or numeric order.
A causal receipt attests the *actual write's* before/after versions, not merely an
earlier check-then-write probe. Host truth, validity/retention/epoch continuity and
these stronger optional capabilities must be established by an adapter contract.
No ordinary filesystem provider is assumed to offer them. A first unadvanced save
and explicitly pinned saves do not require optional causal/non-reuse capability.

The new closed causal evidence variant binds the full dispatched task capture.
Authenticity, current evidence authority, envelope/schema bounds and independent
causality attestation precede processing. Before must equal the separately captured
actual dispatch condition; after must agree with any known written result version.
Known nonapplication plus a claimed write edge is contradictory in either arrival
order. An exact repeated edge is idempotent; differing authoritative edges enter
the same capped contradiction store and fault the destination. A causal edge does
not substitute for the required application result or safe disposition receipt.

To derive, begin with the exact original baseline version and its private anchor.
Traverse retained later own dispatched writes in actual coordinator dispatch order.
Known nonapplication adds no token edge. Each written predecessor must be safely
resolved, uncontested, from the exact same document/binding/registration/procedure,
and have an attested edge matching its dispatched condition and known result token.
Require both declared capabilities, current progression permission, a matching
chain head, a different token in the same epoch and remaining derivation capacity.
Missing/unknown/contradictory evidence, foreign gaps, token reuse or epoch changes
refuse advancement. Record origin, dispatch serial and before/after versions for
each edge separately from the original capture. A final attested destination probe
must match the derived condition; a newly seen probe token is not the derivation.

The derived receipt frame must fit its reserved envelope before dispatch. Refusal
does not launch, consume a dispatch serial or rewrite a queued capture. A resource
probe remains best-effort unless the captured protection requests a supported
conditional write. This mechanism adds no HTTP/network transport or new executor.
Admission preflights the expanded minimum receipt, including worst-width dispatch
serial and initial condition, and an own-chain request's minimum derivation space.
A profile fitting only the older receipt shape rejects before artifact issuance;
later additional edges still require final expanded-frame/derivation admission.

## Acknowledged baseline and output comparison

Each actual launch receives a fresh private dispatch serial. FIFO admission order,
receipt arrival and source revision are not substitutes. Same-key dispatch already
requires known application and attested no-future-effect disposition for every
preceding dispatched attempt. Under those premises, actual own write effects are
ordered by launch: an older own attempt cannot write after a later launch. This
does not order arbitrary external writes or assert current disk contents. It is
a construction from the existing single-flight effect barrier, not a new provider
clock or a sorted opaque token.

Baseline publication is an explicit serialized current-root transition. Recheck
current publication/identity/coverage/companion/version/resource grants and actual
current binding, registration and unique resource owner. Select the latest own
dispatched eligible acknowledgment for that exact context. Eligibility requires
full written application, captured requested acknowledgment strength and uncontested
destination evidence. Synchronization failure remains a written fact, but cannot
qualify an ordinary supported-synchronization acknowledgment. A later unqualified
write remains separately inspectable; selecting an older eligible acknowledgment
does not claim it is the latest disk contents.

Construct baseline bytes from the actual private immutable codec artifact. Record
captured source/settings/binding versions, profile/BOM, origin/provider/procedure,
required/qualified acknowledgment, optional version and dispatch serial. Do not
substitute the current source, compare lengths as equality, or infer a token when
the provider supplied none. Update only sourceBaseline and the publication counter;
preserve current source/settings/comments/history/views/membership. An unchanged
baseline does not publish again. Late duplicates or late older synchronization
receipts cannot regress the chosen newer eligible baseline. Caller stop does not
erase independently acknowledged historical writes. Rebound/disposed targets
cannot acquire an old binding's acknowledgment.

Acknowledged-write anchors are verified against the actual retained private ticket
and artifact, including exact bytes and all baseline fields. Unknown token may
remain unknown in an older historical baseline after the receipt learns a token;
this preserves the earlier fact without inventing a known version in it. Explicit
publication may subsequently record the attributable new version. A tokenless
baseline still supports exact output comparison but cannot authorize the next save
under this version-conditioned profile. No blind external-token refresh is added.

Late authoritative contradiction makes dependent baseline eligibility unavailable
through the private destination fault state; it does not roll back the historical
root record or authored source. Historical acknowledged bytes, unresolved effects,
current intended-output equality and external freshness remain separate facts.
The distinction between writing and requested synchronization follows the existing
ordinary profile; actual [File synchronization](https://doc.rust-lang.org/std/fs/struct.File.html#method.sync_all)
and concurrent-modification guarantees still require actual host evidence.

inspectSourceOutput is a normalized internal projection of §16.5, not a new public
verb or a complete F02/F06 integration. It requires current source/comparison,
identity/binding/coverage, retention and reply/resource authority, including the
permitted historical-baseline comparison. Use the actual source-codec to prepare
current output in a fresh bounded temporary region, compare exact byte arrays
under the combined comparison limit, then retire that temporary artifact. No
handle escapes and no writer issuance/task state or root changes. This avoids
spending the persistent writer's ever-issued quota on repeated reads. Return
current and baseline version identities with equal/different and external freshness
not-established. Equal output at a fresh revision is not revision identity, an
unchanged serialization setting or evidence of current external storage. Invalid/
ambiguous/unavailable output is not guessed equal or silently repaired.

## Dependency retention and finite transitions

Retirement now receives the authority's actual current serialized root. In addition
to work/effect resolution and independent retention/drain release, a written ticket
cannot retire while the live same-binding baseline is unverified or at/before its
dispatch serial. The current producing ticket remains pinned. Any nonstopped queued
same-key capture whose original anchor is at/before that write also pins it: a new
root baseline cannot erase edges still needed by an older queued capture. After
launch, bounded copied derivation evidence and the later ticket's own acknowledged
artifact can retain the necessary attribution; delivery drain remains a trusted
condition for retiring the earlier record. Unknown/contested attempts never gain
retirement by caller cancellation. Missing capacity backpressures, not silent
history truncation or coalescing. Rebind/disposal hold transfer remains integration
work, not a newly supplied lifecycle implementation.

Task/registry/root/tag/issuance/envelope limits remain. Reserve maximum capture,
five bounded evidence envelopes, bounded derivation and one codec artifact per
task. Baseline materialization and exact comparison have separate finite byte
limits; roots obey their declared size/publication-counter bounds. Temporary query
regions are finite logical preparation, not measured physical allocation/RSS.
No local transition waits for I/O. Finite scans/chunks and checked counters bound
these reference transitions; external completion and native/host halting are not
inferred from a closed vocabulary. The capped witness store is still not arbitrary-
union lattice closure or whole-engine categorical completeness.

Section 11.2.2 separately extends the root evidence floor through retained disposal
and key release, using the retained binding until independent provenance discharge;
see lifecycle-products.md. That release does not discharge quiescence, delivery
drain or other consumer holds. Historical late receipts remain distinct from new
mutation admission or a current disposed-binding baseline.

## Conditional arguments and executable evidence

Under the existing actual-current-root/serialized-transition, policy/identity/
coverage, provider version/causality and safe-disposition premises:

1. Induction over accepted chain edges preserves original capture and establishes
   each derived head from an attributable same-context predecessor. Non-reuse and
   same-epoch matching exclude inferring an edge across ABA/foreign gaps; without
   those premises or evidence, the reference refuses progression.
2. The per-key safe-effect barrier orders own writes by actual launch. Taking the
   greatest eligible private serial therefore cannot select an older own eligible
   acknowledgment merely because its result arrived last. This is not a global
   external-storage freshness or arbitrary concurrent-write ordering theorem.
3. Actual artifact extraction and exact baseline verification preserve byte and
   version attribution. Root-copy publication changes only baseline/publication;
   pure temporary serialization compares intended bytes without authoring or
   consuming persistent writer identity. Later contradiction changes eligibility,
   never historical source/root facts.
4. Baseline and queued-anchor holds prevent deletion of an edge before its required
   use. Current-root floors can advance only through actual verified tickets; safe
   predecessor retirement does not authorize unknown effects or reuse origins.

These are authored conditional arguments, not proof-assistant-checked induction.
