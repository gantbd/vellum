# Discovery query argument capture

The three existing F01 queries accept exact typed/dynamic semantic arguments:
list, inspect and advisory enablement. Their native field declarations are shared
with bounded capture. No query, public acquisition verb, self-discovery profile,
transport, identity representation or command executor is added.

List retains a positive safe-integer limit and an explicit nullable continuation.
Inspect retains an entry role. Advisory enablement retains separate entry,
variant and target roles. Every form retains its original context and profile.
The profile string does not select a supported native profile by itself, and a
structurally valid page limit still faces the native page ceiling.

## Data ownership and native identity

Capture checks the exact route tuple, family/name, operation, version, fields,
scalar domains and recipient-context fields. Canonical data owns ordinary
request values, the recipient context and byte/node/depth limits. Opaque roles
are represented by null shadows plus a fixed role list in that data; their
original objects remain outside traversal and cloning.

Typed/dynamic normalization agrees on the canonical data and every original
role identity. Reconstructed native requests restore those exact objects.
Copies, foreign handles and equal-looking selectors may normalize but remain
native refusals. Cursor query/context binding, current profile, disclosure,
target advice, authority loss and protected context lifetime remain native
obligations. Normalization cannot revive a stopped context or repair a selector.

Exact data descriptors reject getters, symbols, hidden fields and unsupported
prototypes before canonical capture. Ordinary cycles and malformed Unicode
refuse through the bounded data copier. Opaque object contents are not evaluated;
this does not establish hostile proxy isolation or resource limits for arbitrary
host code.

## Boundedness and preservation argument

The three operation cases have fixed field and role counts. Each accepted
envelope selects one existing native form. Ordinary values pass the bounded
UTF-8 byte/node/depth copier; the maximum supplied by the owning caller
independently caps capture bytes. No numeric default is selected.

For a successful normalization, native reconstruction preserves every ordinary
field value and original role. Route spelling is excluded from canonical
meaning. The normalized value is not a grant, native query result or proof that
the current owner can admit it. Native observation remains read-only with respect
to the mutation root and parent invocation ledger.

These are logical capture limits, not actual-parent temporary reservations,
physical allocation bounds or a prepaid query gateway. Metadata/selector/reply
retention remains charged by the existing discovery owner. A complete facade
integration must preserve both sets of obligations without hiding retained costs.

## Instrumentation and evidence

At IF-01/02 and PATH-02, distinguish shape refusal, bounded capture, native
profile/identity/currentness refusal and actual query release. Existing
INS-01/03/05/08/12/13 MELT, golden/RED and USE perspectives apply at those
boundaries. STRIDE/LINDDUN/privacy/hazard cases include selector substitution,
recipient/profile confusion, stale cursors, regrant revival and linkage through
raw reference labels. Record bounded operation/disposition classes, not handles,
recipient identities, metadata bodies or authored content.

Nine controls cover all ten existing profiles through both routes: 61 actual
native query results, 88 malformed refusals, 36 exact capture boundaries, 21
native role/profile/page/recipient refusals and four absorbing loss/stop cases.
Twenty-eight targeted copied-graph mutations fail semantic assertions after an
unchanged baseline. Construction and process/tool failures are not detections.

The selected engine graph includes the normalizer and reaches 113 modules with
frontend exclusion and clean/ordered initialization obligations. Components,
interfaces and the 76/11 partition remain unchanged.

Full frozen verification and endpoint reconciliation remain adoption gates.
Actual-parent gateway ownership, closed public result products, self-discovery,
events, installed instrumentation, host/physical/measurement evidence and
independent assurance remain separate obligations. This finite capture corpus
does not prove whole-engine categorical completeness.
