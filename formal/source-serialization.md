# Document serialization metadata evidence

Specification §22.3.1.6 adds explicit intrinsic output-format intent to the
existing F16 semantic-settings job. It does not turn a configuration-domain key
into document metadata or invoke codec, storage or frontend behavior implicitly.

## Contract and ownership

source-serialization.mjs supplies the bounded decision and shared input declaration;
source-serialization-state.mjs retains private owner/domain/ticket-bound plans.
The actual invocation owner prepares, captures, publishes and retires them through
its common settings path. The dedicated profile bounds arguments and plan bytes;
the actual parent independently bounds the full wrapper and candidate root.
Reference JSON byte charges do not establish physical memory accounting.

Current target/context-bound write facts, complete execution context/profile,
metadata generation and mandatory plus declared dependencies govern service.
They remain trusted host premises, not evidence that a real policy engine granted
the action. Source revision does not govern metadata-only intent unless explicitly
declared. Source/history/annotations/bindings/baselines and the actual source
transform journal retain their existing meanings.

## Executable evidence

[Neovim's primary option contracts](https://raw.githubusercontent.com/neovim/neovim/master/runtime/doc/options.txt)
keep BOM and encoding intent local to a buffer, restore an unchanged BOM on write,
and distinguish format-related modified state from text changes. This supports
the separation of output intent from source content. It does not establish
Vellum's authority, generation, atomicity or writer-ownership properties, nor
select Neovim's conversion or newline defaults.

Run node formal/source-serialization-checks.mjs. Coherent generated copies alone
receive a private test-owner accessor; the actual invocation module exports none.
Two typed/dynamic publications, 33 service cases, five target cases, ten profile
cases, 23 malformed cases, nine budget boundaries and five counter cases check
the actual participant. Separate decision checks cover three source frames and
81 strict gate cases. A valid no-op survives exhausted unused counters; changed
metadata requires capacity. Configuration registry absence does not block it.

The actual native source writer retains its old admitted capture and logical
ownership across metadata publication. An old-format dispatch and late baseline
acknowledgment retain the old generation and leave current intended output
different. Explicit disposition/quiescence remains necessary; a new-format capture
and qualified acknowledgment then establish current equality without source edits.
This is supplied-evidence composition, not a physical filesystem write.

An injected trusted-fact getter failure exercises the common publisher's unknown/
faulted path, admission fencing and protected retirement. Root identity is
preserved in that trace; this is not containment evidence for all faults.
Eleven exact source mutations challenge generation, target grant/context,
dependencies, parent/root bounds, retirement, identifier bytes, strict grants,
registry independence and closed profile validation. Only assertion failures
after a coherent baseline count as kills, not import or syntax failures.

Discovery uses the same guarded declaration as its seventh F16 outer form.
The independent standard validator now checks 94 instances across ten forms,
including scoped definition/lifecycle and serialization activation. Cancellation
retains the same job kinds over thirty forms/twelve kinds, 480 gate/240 context/
sixty race cases and 7,770 traces with 21,780 edges. Existing negative controls remain.

## Remaining gates and instrumentation

No new solver condition or full F16 implementation is claimed. Public/scoped
format codecs and all result/events, policy/host truth, physical accounting,
production packages, concurrent/crash behavior and independent assurance remain.
Section 22.3.1.9 supplies selected metadata-only scoped bases/private lowering;
see scoped-serialization.md for its separate evidence and limits.

changed/no-op publication, capture refusal, acknowledgment and quiescence. Apply
