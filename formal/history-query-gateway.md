# Decoded history queries and owner workspace

The existing F04 native history owner dispatches typed and dynamic frontier,
availability and permitted-blocking-detail requests through the same native query.
It parents temporary decoding workspace as well as its existing declared history
reservation. The invocation domain supplies the authoritative history root; that
association is not proof of an invocation-domain or global budget reservation.
This follows the existing bounded F02/F03 decoder pattern without adding an
operation, transport, scheduler or execution mode.

## Capture and fixed dispatch

Resolve the actual inspection owner, excluding stopped, faulted or already-busy
owners, before accepting decoding work. Reserve the finite limit-classification
frame against that owner's actual current headroom. Copy the existing three-field
limit profile, then safely calculate seven times its request-byte ceiling. Reserve
that complete logical workspace against the same headroom before ordinary input
copying. Reject overflow or insufficient capacity without changing native history.

The seven frames cover the facade envelope, authority context, canonical capture,
limits, descriptor, facts and producer request. They are a declared logical
reservation, not physical allocation measurements. The supplied request ceiling
does not replace the owner's independent held bound. The history capture-byte
limit describes a different product and must not substitute for the request limit.
No numeric product default is selected.

Normalize the existing exact argument forms while retaining the original opaque
history context. Compare the copied eight-field authority context with the actual
history owner. Separately copy the current-facts packet under independent byte,
node and depth limits. Do not read raw fact getters, coerce unknown values to
Boolean grants or infer authority from a well-formed packet. Dispatch only to the
fixed native owner with the original context, copied meaning and copied facts.
Native root/basis, projection, current release and result checks remain mandatory.

An unknown well-formed profile or alias is not repaired by decoding. Foreign
owners/handles, mismatched authority frames and malformed requests cannot lend
accepted current-loss observations to another context. Recognized whole-context
loss remains absorbing under the native rules; unknown facts merely withhold.
Empty, eligible, blocked and unavailable-detail results retain their existing
meanings. Query advice neither reserves a frontier nor authorizes reversal.

## Protected completion and conditional reasoning

Hold the busy fence through the fixed native query. On every return path, refund
exactly the temporary amount reserved, clear the recorded workspace and leave the
busy state. A decoder exception fences the history owner. A native result invariant
can fence it independently. In either case refund only decoding workspace: retain
native contexts, the owner's base reservation and spent issuance, with protected
closing/retirement still available. A late exception after this read-only query
does not imply rollback or general crash recovery.

The classification reservation plus seven finite request frames bounds the declared
temporary charge. Each successful reservation checks its actual parent headroom
before incrementing it. A single tally records exactly what the finalizer owes;
neither ordinary refusal nor a fault skips that finalizer. Fixed finite dispatch,
the existing bounded data copier and bounded native query supply conditional
termination under the serialized trusted-runtime premises. The busy fence denies
nested facade admission rather than creating a recursive command language.

Host/global admission and retention truth, raw ingress/preallocation/reflection,
physical peaks, concurrency, abrupt termination and measured performance remain
separate obligations. This local charge does not close those refinements or prove
categorical completeness. No user callback or provider executes inside this path.
The verification probes below are compiled first-party test variants, not runtime
hooks.

must distinguish classification, workspace admission, argument/current-fact capture,

the actual owner's temporary occupancy, saturation/refusal, busy state and held
native pressure. Compare reserved, refunded and remaining declared amounts rather
than treating unavailable as a successful discharge observation.

reentry and resource denial. LINDDUN/privacy/hazard review challenges scope linkage,
hidden-capacity inference and raw facts/error payload retention. Do not log opaque
handles, aliases, authored/history data or raw authority packets. Existing
recipient-scoped release governs detailed diagnostics and trace linkage. Neither
trace evidence nor an owner-local metric is authority or proof of global capacity.
Runtime observation delivery and numeric service thresholds remain implementation
and measurement gates.

## Evidence and remaining gates

`history-query-gateway-mutations.mjs` requires a coherent copied-graph baseline and
detects 27 semantic mutations. Every mutant runs both complete gateway and fixed
fault/reentry corpora. Process/signal/timeout, syntax and nonassertion failures do
not count as detections. Eleven gateway controls cover 24 native route/profile
cases, twelve exact workspace/facts boundaries, 77 refusals and five absorbing
loss cases.

Six fixed fault stages cover 36 native route cases; four reentry stages cover
24. Three additional classification boundaries independently challenge the initial
reservation. Probe reentry is limited to one nested attempt so a broken fence
cannot create an unbounded test recursion. Attempt counters separately check that
a faulted owner does not readmit decoding work. Roots, native context obligations,
base reservation and lifetime issuance remain intact while temporary work refunds.

Selected post-import execution wraps 143 filesystem/process callables. The complete
eleven-control corpus, including fixture operations, makes no baseline calls; three
injected query call types are detected. Import isolation, all-host containment and
production dependency separation do not follow. Existing history/invalidation/
argument/result banks retain fourteen/eight/24/31 mutants and pass. Three result
mutation construction targets now select the original native-query catch exactly,
not the added decoder catch; their semantic challenges remain unchanged.

Full frozen verification and endpoint reconciliation remain required before
adoption. Complete F04 discovery/selector/event/codec products, actual policy/alias/
coverage/retention truth, all-host/global/physical/concurrent/crash refinement,
measurement and independent assurance remain open. No whole completion row closes.
