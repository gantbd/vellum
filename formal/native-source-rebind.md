## Publication and ownership

The trusted coordinator obtains the actual current root and accepts exactly the
lifecycle, membership and binding profiles. Current registered identity and logical
continuity, exact binding and registration generations, complete ordinary-pair
coverage and current source/annotation resource distinction remain mandatory.
It never accepts a caller-supplied replacement root or manufactures identity facts.

A private single-use certificate binds the actual domain, exact before-root,
closed request, reconstructed allowed delta and actual writer guard. Final
installation rechecks twenty exact-true facts, structured current pair evidence,
actual writer tasks/conflicts on both old and new keys, native size caps and
outstanding baseline-promise floors. A pending same-document export reservation
blocks rebinding. New pending work or contradictory late evidence invalidates
already prepared work. Safe disposition and application knowledge can permit
rebinding before worker quiescence; they do not release retained work evidence.

Same-context activation is unchanged, preserving its baseline and historical
qualifiers. A changed context advances binding/publication generations, archives
the old binding and source baseline, clears the current source baseline and moves
only the resource-owner relation. Scratch first-binding establishes generation 1
without fabricating old history. Absent initial history is known-empty only in the
existing initialized profile; explicit null, malformed rows and bounded archive
overflow refuse. Source, serialization, annotations, edit history, views,
workspaces and reader/writer/codec/invocation/pool ledgers remain framed. Metadata
journal carry preserves actual source transform evidence without a new edit receipt.

## Conditional arguments

For the accepted finite profile, exact delta reconstruction plus actual before-root
identity gives a serialized frame argument: no peer/source/history field can change
outside the declared association delta. An intervening publication invalidates
preparation. Final pair evidence preserves distinct ordinary destinations; a prior
positive comparison cannot authorize a stale or colliding pair. Actual writer
guard revalidation excludes known unresolved effects and pending export intents.
Freezing, consuming and installing the certificate prevents reuse of the same
prepared delta. All loops range over bounded current inventories; the closed
request vocabulary selects a finite validation path with no retry loop or I/O.
These are conditional authored arguments about the scoped reference, not an
unconditional host oracle, category-theoretic completeness theorem or production
concurrency/crash proof.
