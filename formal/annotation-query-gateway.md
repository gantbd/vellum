# Decoded annotation queries

Section 22.1.15 adds closed result checks and actual staged record/continuation
bindings. Native prepublication faults install no selectors. Later facade faults
retain any complete selector set already published, preserve monotonic issuance,
fence admission and refund only the temporary decoding workspace. Withheld facets
and detached placement remain distinct; see annotation-query-results.md.

The selected F03 facade preserves enumeration, record inspection and target
location through existing typed and dynamic routes. Current and retained
annotation/combined contexts and coherent-set members use the same argument
meaning. This is a design reference, not a production ABI or a transport codec.

## Arguments and native ownership

`annotation-query-arguments.mjs` derives its three declarations from the same
catalog as the native reader. Enumeration has first-page and continuation shapes.
Exact inert routing tuples, document identities, profile and numeric page limits
are captured under byte/node/depth ceilings. Unsupported nonempty profiles and
page limits beyond a particular owner's profile reach that owner; normalization
does not repair them or grant access.

Snapshot and record/continuation identities remain original opaque capabilities
outside copied data. Their roles are distinct and included in canonical meaning.
The normalizer does not traverse or authenticate them. The actual pool handle
selects a fixed annotation or coherent-member native port, not a caller label or
callback. Native lookup binds record and continuation kind, original context or
member, and continuation page size before observing current loss. Malformed or
foreign selectors therefore cannot poison another retained context.

The authority/engine frame and independent native current scope/facts remain
separate. Known loss invalidates the recognized original context or whole coherent
parent before page-capacity or transient-resource refusal can mask it. Unknown
facts withhold without establishing loss. A copied context remains usable after
the original is stopped and retired; no recapture of a newer authored root occurs.

## Workspace and release

The actual invocation parent reserves classification and seven bounded logical
frames for envelope, authority, canonical record, limits, descriptor, current/facts
packet and producer request. The byte maximum is the lesser of the input ceiling
and owner intent ceiling. A busy fence excludes reentry; protected cleanup refunds
only this workspace. Native reply and selector reservations and spent issuance
remain separately owned.

Fresh pages publish complete native record/continuation selector sets. Returned
selectors immediately support later facade inspection, location and continuation
queries. Repeated pages reuse original selectors. Native capacity refusal publishes
no partial set. Fixed faults before querying fence owner admission, refund the
temporary workspace and leave native state and authored roots unchanged; they do
not prove rollback after selector publication or crash recovery.

## Executable evidence and limits

- `node formal/annotation-query-argument-mutations.mjs` checks four shapes,
  32 native compositions, 72 malformed refusals, 48 capture boundaries, eight
  controls and 23 assertion-detected semantic mutations.
- `node formal/annotation-query-gateway-mutations.mjs` checks 96 gateway cases,
  six actual-parent headroom boundaries, 87 refusals, nine controls and fourteen
  assertion-detected semantic mutations.
- `node formal/annotation-query-gateway-fault-checks.mjs` checks baseline,
  classification fault, workspace fault and reentry across six native branches.
- `node formal/annotation-query-gateway-substrate-checks.mjs` intercepts 143
  callable filesystem/process exports after import, observes no baseline calls
  and detects three injected pre-query call types across six branches each.

Coherent copied-graph baselines precede mutations; construction failures do not
count as semantic detections. Raw ingress and descriptor enumeration, physical/
global memory, measured ceilings, host/policy truth, complete public discovery/
result/event/selector products, asynchronous lifetimes, production dependency
isolation and independent assurance remain obligations. Full frozen verification
and endpoint reconciliation are required before adoption. The finite cases do not
prove categorical or unbounded completeness.

`node formal/read-facade-composition-checks.mjs` connects actual decoded F02
handoff to decoded F03 queries across all four typed/dynamic route combinations.
Twenty-four current/retained owner chains produce 72 page/record/location products.
Original retirement leaves copies usable; later known loss remains absorbing and
temporary workspace refunds independently at both boundaries. Twelve source-only
cases refuse annotation promotion without poisoning valid source reads. These
checks compose the selected gateways, not every public operation or lifetime.
