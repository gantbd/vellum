# Acknowledged annotation baselines

Specification §16.5.3 composes the actual native annotation producer, retained
codec artifacts, shared destination writer and activated ordinary binding pair.
The precedent is the accepted source-baseline contract in §16.5.1 and
[source-save-continuity.md](source-save-continuity.md): explicit acknowledgment
attribution, explicit baseline publication and exact output comparison are
separate from current external freshness. This is a scoped executable reference
and authored conditional argument, not an independent Cleanroom certification.

## Admission and publication

The existing explicit export operation privately records its original ordinary
annotation binding only when complete current pair validation, typed ownership
and registration association succeed at admission. Otherwise that export cannot
later become this binding's baseline. Its provider receipt retains its export
binding generation; the ordinary binding generation is a separate baseline field.
No export or acknowledgment automatically publishes a baseline.

The publisher checks thirteen exact-true current grants, the actual writer owner,
document incarnation, complete current pair, exact original ordinary annotation
binding, whole captured registration and unique typed owner. The latest eligible
own dispatch serial wins; its original context must match the requested context.
No older-context fallback or receipt-arrival ordering is inferred. Eligibility
requires written application, captured acknowledgment strength and uncontested
evidence. Stop does not erase an independently acknowledged effect.

Initial field absence needs a current explicit attestation. A present non-null
baseline must reconstruct exactly from the actual retained ticket/artifact;
corruption cannot be silently repaired. Baseline publication copies actual bytes
and attribution under its byte bound, changes only annotationBaseline and one
publication counter, and checks the complete candidate-root bound. Exact unchanged
metadata needs no new counter. A historical tokenless baseline remains valid
when a receipt later learns a token; explicit publication may adopt that fact.

## Comparison and retention

Section 16.5.14 additionally authenticates loaded captures through explicitly
attached actual read owners, with no fabricated write acknowledgment; see
annotation-loaded-baseline.md. The shared comparison and qualified replacement
path recognizes that separately checked baseline kind. The arguments and counts
below retain this acknowledged-write slice's scope.

Comparison checks fifteen exact-true current grants, the original context, current
pair and baseline anchor. The actual native document's complete source and
annotation fields must match the host root, not merely its version labels. The
actual native producer captures temporary current bytes under the remaining
combined comparison budget. Direct octet equality returns equal/different and
bounded copied version/origin metadata, never bodies or a discrepancy offset.
External freshness remains not-established. No root, held occupancy or persistent
writer/codec issuance changes. Different set versions can produce identical empty
snapshots after undo and redo; same lengths do not imply equality.

The common writer's retirement path checks ordinary annotation bindings and
retained annotationBindingHistory. Actual producing baselines pin their tickets
and artifacts. Written attempts still eligible for later baseline adoption also
remain pinned. A newer eligible baseline releases only older unneeded producers;
retained historical bindings can keep their own producers pinned. Unknown history
or an inventory older than the captured binding generation refuses retirement.
Field absence means empty history only in this initial normalized profile; all
future binding-history producers still require coherent integration.

## Conditional arguments

For finite normalized inputs, immutable private artifacts, serialized candidate
installation and truthful current host facts:

1. Publication can attribute only an actual retained annotation write whose
   original ordinary binding and registration remain current. Cloned handles,
   foreign owners, later rebinding and retroactive association cannot qualify.
2. Dispatch-serial election under the existing per-destination disposition barrier
   prevents a late older receipt from regressing the newest eligible own baseline.
   It says nothing about unrelated external writers or current disk contents.
3. Every successful changed candidate frames authored source, annotations, views,
   source baseline and all other root fields. Only the annotation baseline and
   one finite safe publication advance differ; refusal returns the original root.
4. Exact comparison reconstructs the historical anchor and scans bounded complete
   byte strings. It halts without persistent issuance and does not equate semantic
   content, versions or hashes with exact output.
5. Retirement cannot remove an actual producer needed by current or declared
   retained binding evidence. Missing coverage, stale generations and unknown
   history are not positive discharge. The argument assumes truthful complete
   root/history coverage; it does not establish every lifecycle producer.

## Executable evidence and remaining gates

annotation-baseline-checks.mjs exercises 42 actual native capture/undo/redo cases
over fourteen variants, all 8,192 publication and 32,768 comparison masks,
27 controls and 27 semantic mutations after a passing dynamically rewired
source-writer/binding-pair baseline. Controls cover frozen artifacts, strict grants,
original association, complete binding/registration/context, source-read
independence, synchronization failure, late receipts and contradiction, no-op
overflow, same-length edits, equal empty output, capacity refusal, token enrichment,
retained history, stale inventory, actual chunking, native coherence and foreign
authority. Assertion failures, not import or syntax failures, kill mutants.

This is an explicit export followed by an independently authorized baseline
publication. A write receipt may remain valid while publication capacity refuses.
Ordinary annotation save admission must preflight any promised baseline capacity;
ordinary save/load, rebind/unbind and all history routes remain open. Actual host
identity, policy, retention/discharge and provider truth; whole public query,
invocation/replay/events and atomic native root/companion installation; physical
and engine-global accounting; hostile decoding; production/concurrency refinement
and independent assurance are not proved. No new SMT conditions or public verbs
are introduced; the existing solver total remains 234 across fourteen manifests.

INS-03/04/07/08/12 and PATH-05 distinguish attempted writes, acknowledged strength,
baseline adoption/refusal, byte equality, unknown freshness and pinned occupancy.
MELT, RED/USE/golden signals, STRIDE and LINDDUN apply to wrong-binding attribution,
forged receipts, stale grants, history loss, quota pressure and equality correlation.
This is an instrumentation contract, not installed telemetry or a timing proof;
never place content, paths, contexts, origins, identities or tokens in metric labels.
