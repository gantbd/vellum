# Owned pure source rebind invocations

Specification §11.2.14 adds the existing source-rebind/1 product to the owned
lifecycle-invocation/1 interpreter. The operation changes a local association,
not a file, document identity, source revision or annotation owner. The native
contract and frame remain those of [native-source-rebind.md](native-source-rebind.md)
and §11.2.8; no new rename, save, alias or overwrite policy is selected.

## Current candidate and attenuated writer dependency

The nested request remains exactly contract, operation: activate-source-binding,
document, expectedBinding, provider, resource and expectedRegistration. It names
an explicit currently registered target, not a path inferred from UI focus.
Existing current pair/distinction, target identity/continuity/uniqueness, retained
history, destination authority and both-destination writer barriers still apply.
Unknown aliases, stale generations and an annotation destination cannot satisfy
the ordinary source role. Binding authority does not imply source disclosure,
source writing, document disposal or authority to issue an external write.

The fixed native rebind preparer is extracted for reuse by the direct native
publisher and the owned lifecycle service. Both still derive from their actual
current root and seal the same private native frame and source-rebind writer guard.
The stable lifecycle writer inspection now also permits pure rebind-candidate and
rebind-guard preparation. These read the actual registry's task/fault records and
return internal candidates/certificates; neither mutates the writer ledger nor
installs a root. Effect admission, dispatch, SaveAs producer transitions and other
effect-producing APIs still require their original owner/producer contracts.

The owned plan retains immutable request/profile and exact inspection identity,
not a prepared replacement root. Service uses current state and all native rebind
facts. Replacing the target registration after admission refuses rather than
borrowing its new locator or generation. New exports on the old or proposed
destination also block; cancellation alone does not remove their reservations.
After the owning safe-release transition, a fresh invocation can rebind. A refused
invocation is terminal and never silently retries under new facts.

On a real transition, preserve source/annotation/lifecycle state, archive the exact
old binding and source baseline, advance the association generation, clear the
new source baseline and update only the admitted resource-owner relationship.
A scratch document's first association establishes no saved baseline or invented
prior history. An identical current association is validated unchanged and retains
its baseline/history. These properties reuse the native frame rather than a
second rebind implementation.

The adapter maps native rebound to common applied; native unchanged stays
unchanged. The recipient receipt remains invocation, applied/unchanged status,
operation: source-rebind and document identity. The operation plus status preserves
the distinction without exposing private binding or writer data. Current result
ceilings/context/policy, atomic root/outcome/receipt publication, journal carry,
cancellation/replay and one-preparation-per-slot rules remain those of §11.2.13.
Opaque remote references and allocation-order non-linkability remain gates.

## Conditional preservation and evidence

Under the existing supported-state, truthful current host/compiler/policy/coverage,
first-party factory and serialized-owner premises:

1. Fixed routing selects the existing rebind preparer. Its owned native certificate
   checks exact before-root/candidate/association history and actual writer guards.
   The adapter adds no alternate mutation path or weakened binding predicate.
2. The inspection names the actual writer record. Current task/registration/pair
   changes are revalidated during service and final commit; no copied empty ledger,
   guessed uniqueness or Boolean quiescence can replace these checks.
3. Native rebound and unchanged map to the existing closed local outcomes without
   adding effect evidence. No write acknowledgment or savedness can be inferred
   from association success. The receipt remains subject to the original admission
   ceiling and current historical-document release rights.
4. The additional request form is finite and uses existing bounded scans/copies
   and one local commit or refusal. It does not establish provider termination,
   whole-editor categorical closure or a global lifecycle lattice.

These are authored conditional reduction/trace arguments, not machine-checked
induction or independent certification. The direct native rebind suite retains
42 cases, 16,384 common fact vectors, eighteen additional strict cases, seventeen
controls and thirteen mutants with a passing rewired baseline.

The current owned lifecycle suite now covers nine native products across 42
annotation/history stages: 756 typed/dynamic publications, 256 admission cases,
477 strict service refusals, 72 release masks, twenty-two controls and 28 semantic
mutants in two exact fourteen-case banks. Seven added controls cover authored
frames/history, unchanged baseline preservation, stale/alias refusal, registration
replacement, actual native export reservations on both destinations, binding-only
authority and first scratch association. The two new mutants challenge routing
and rebound-to-applied normalization. Every bank has a passing baseline; only
assertion failures count as kills. The existing 28 families/87 labels, ten native
job kinds, shared cancellation coverage and 234 SMT conditions/fourteen manifests
are unchanged.

IF-01/03/04/07/08/10 and INS-01/02/03/04/07/08/09/12/13 distinguish admission,
binding publication/refusal, stale registration, actual writer blockage, safe
reservation release and current result disclosure. MELT/RED/USE/golden signals
separate queue/service/release latency and bounded pressure; STRIDE/LINDDUN cover
alias/role spoofing, old-generation replay, producer-obligation loss, private
association leakage and activity linkage. Do not use raw resource, document,
locator, binding, task, origin, inspection or invocation data as metric labels.
Installed signals and numeric objectives remain measurement/implementation work.

SaveAs/load activation invocation and producer-state commits, complete F17 events,
registry/descriptor binding, remote encodings, actual host identity/policy/coverage/
retention/compiler truth, packaging/frontends, owner recovery, physical/global/
concurrent/crash refinement and independent assurance remain gates. No whole F17,
