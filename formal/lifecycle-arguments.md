# Selected lifecycle argument capture

Five existing document-lifecycle requests map to four existing F17 variants:
create-scratch; attach-view and detach-view under attach-detach-view; membership;
and dispose. Lower fields come from the native guard's catalog. The lifecycle
wrapper and seven-field owner context retain their existing declarations. Private
binding/provenance discharge is not promoted into new public verbs. Rebind,
loaded activation and container lifecycle products keep their separate contracts.

Typed family 16 and dynamic change-document-lifecycle envelopes require version 1,
the matching variant, exact ordinary data fields and the existing wrapper
contract/operation/profile. The issued invocation is a bounded string value, not
an invented opaque object. Preserve it without coercion or repair. Immutable owned
request/context capture uses independent byte/node/depth limits; its byte ceiling
intersects the caller's maximum. Captured data is not an authenticated capability.

Both routes retain the same request/context meaning for the same native invocation
value. Producer reconstruction may reuse a prepared intent only through the actual
owner's current checks. Caller mutation cannot alter the capture. Unknown fields,
mismatched variants, private discharge requests, accessors and unsupported ordinary
data refuse. Shape does not establish UTF-8/source validity, current revisions,
scope authority, writer coverage or final publication. A captured source byte 999
is an explicit native-refused counterexample.

The reference exercises ten actual-owner compositions, 236 refusal cases, nine
exact logical boundaries, two invocation-value cases and twelve targeted mutants;
see formal/lifecycle-arguments.md. Actual-parent gateway accounting/refund, complete
F17 products/discovery/events, hostile proxy/native-code containment, physical/
global bounds, installed instrumentation and independent assurance remain open.
Existing IF-01/03/04/07/08 and INS-01/02/03/04/07/08/09/12/13 distinguish capture/
refusal from admission, publication and release. Invocation/context/source values
are not ordinary diagnostic labels. Full frozen qualification and endpoint
reconciliation remain adoption gates.
