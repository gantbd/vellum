## Data and authority

Exact request fields come from the native source-product declaration. Routing,
contract/variant agreement, document identity, profile and numeric fields are
captured under independent byte/node/depth ceilings. Original opaque snapshot
identity is bound without traversal and restored only for the native producer.
Getters, symbols, cycles, unsupported prototypes and extra fields refuse as data.
These checks are not hostile-Proxy containment or a serialized-input codec.

The authority/engine frame binds the actual domain, not source read permission.
An original native pool handle chooses one fixed first-party read port, never a
caller issuer label or callback. Source/combined current recipient scopes differ
from coherent-set complete parent/member facts; independently copied current data
preserves that distinction. Known bound source/peer loss remains observable before
transient resourcesReady refusal. Unknown facts and transient shortages withhold
without stopping an otherwise current context. Foreign/malformed requests and
cross-pool handles do not poison another context. UTF8 boundaries, actual extents
and captured profiles remain native checks; normalization never repairs them.

## Ownership and logical units

Reserve the fixed serialized three-limit classification frame at largest safe
integer values before bounded copying. Then reserve seven frames at
min(maxRequestBytes, owner.maxIntentBytes) against actual parent headroom.
Envelope, authority, canonical record, limits, descriptor, current/facts packet
and producer request each fit that bound. Hold the charge through the native query
and refund exactly those temporary units in protected cleanup. Reject reentry.
Classification or pre-query surprises fence the owner without native query effects.

The existing native owner separately reserves reply/capture/registry obligations.
Do not refund its fixed envelope, change lifetime issuance or stop/discharge a
context merely because temporary decoding finished. A recognized loss may stop
its original context under the native contract. Replies retain original context
identity and native owned-value semantics. This declared logical envelope adds no
production numeric default or physical/global allocation guarantee. Raw descriptor
enumeration/host-object allocation and bounded serialized ingress remain separate
implementation obligations; the copied-frame envelope does not measure them. Pre-query
probes do not prove post-query crash recovery or general fault containment.
