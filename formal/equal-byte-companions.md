# Equal source bytes and meaningful companion effects

Specification §6.4.1 closes the normalized compound publisher's former equal-byte
mapping refusal. Existing F11/F13/F14, selection and search references now distinguish
source text, automatic annotation placement, selection and authored-history effects.
This is scoped design/reference evidence, not a proof of every companion/profile,
complete recipient noninterference or production/independent assurance.

## Precedent and governing rules

[CodeMirror state 6.5.2 transactions](https://raw.githubusercontent.com/codemirror/state/6.5.2/src/transaction.ts)
separate document changes, selection and state effects within one transaction.
Its [state construction](https://raw.githubusercontent.com/codemirror/state/6.5.2/src/state.ts)
builds a new state from those parts. This supports separate semantic projections,
not importing CodeMirror's callback model, document identity or history policy.
The adopted Vellum rules remain requirements §§5.2/5.8/15.5 and specification §6.4:
equal bytes do not prove complete identity; source and annotation generations differ;
automatic placement mapping is not an authored annotation-history participant.

## Classification and publication

Validate the exact source, private annotation-set and required current view dependencies,
rights, stop, compatibility and resource premises before classifying. Apply the exact
original-snapshot transforms to current annotation placements even when emitted bytes
equal the original. Content-sensitive targets lose original-byte identity under
replacement; inserted equal values do not resurrect it. Positional targets retain
the adopted affinity/collapse semantics. Detached evidence stays detached without
an explicit justified reattachment.

Classify the actual semantic projections before generating bookkeeping:

| Changed projection | Local versions and history |
|---|---|
| None | Validated unchanged success; preserve publication, all versions and history |
| Automatic placement only | One publication and changed annotation-set generation; preserve source revision, authored body/target versions, undo groups/frontiers and views |
| Selection plus optional automatic placement | One publication, changed selection generations and any changed annotation set; preserve equal source revision and source/authored undo history |
| Authored body or target plus automatic placement | One publication; journal only actual authored participants, with independent versions and existing linked frontier rules |
| Real text change in another compound participant | Journal/version that actual text participant; equal-byte mapping in another document does not invent a source-history participant there |

The actual compound publisher implements the placement-only branch. The selection
publisher preserves an already-applied mapping candidate even when source and view
comparisons are equal; it must not return the old root as unchanged. Selection effects
join that same publication. Owned search replacement also keeps the compound candidate.
The clipboard reference's former equal-byte refusal control now checks real application
with unchanged source revision/history. These are shared paths, not a second edit engine.

Required publication, annotation and selection counters refuse on exhaustion; true
identity needs no unused new counter. Existing current rights/complete companion and
bounded-work predicates remain premises. Derived mapping alone does not create or
invalidate authored undo/redo entries. If an authored body participates, native F14
undo reverses the body while preserving current conservative detached placement.
Mixed-document undo reverses only the real authored participants. No automatic
reattachment or general retained target-history restoration is inferred.

Equal source and source revision do not mint a parser source-transform receipt.
The parser-input reference reports unchanged byte input; annotation/view contexts
still invalidate under their own generations. This does not make all structural
or annotation consumers source-only, or prove their native ownership/refinement.

## Conditional arguments and checks

Assume a valid serialized bounded root, correct current authorization/identity/
companion facts and sound adopted mapping operators. Exact comparison of the staged
placements separates identity from a real mapping effect. The mapping branch frames
source/authored/history projections, while ordinary selection publication preserves
that candidate and changes only required current view state. One publication composes
all changed local parts; refusal returns the supplied root unchanged. New history
is built only from the actual authored change list, so an automatic map cannot
acquire another annotation's authored frontier or fabricate a source undo entry.

The independent original-byte-survival oracle checks 8,060 single- and paired-edit
cases, including adjacent/disjoint replacements, both point profiles/affinities,
content ranges, UTF-8 multibyte scalars and CR/LF. It does not call the runtime
interval-coverage helper to decide content survival. There are 256 compound/selection
gate decisions and thirteen controls, plus eleven assertion-rejected semantic
mutants. Controls exercise actual compound/selection/search/native F14/parser paths,
mixed authored/derived publication, counter exhaustion, stale private/view dependencies,
redo preservation, detached evidence and source/history frames across hidden worlds.

The paired hidden-world control proves only equality of its tested source/version/
history/view projection. Internal Applied versus Unchanged, global publication and
raw annotation sets differ: public outcome, event, status, timing and cache-release
projection must not disclose those hidden differences. Complete noninterference is
explicitly not proved. Finite cases and these authored arguments are not general
induction, new SMT laws or categorical completeness. Earlier universal proof flags
remain false; the new ledger names the normalized profiles actually checked here.

## Instrumentation and remaining gates

INS-01/02 distinguish classifier admission, meaningful local publication and validated
identity; INS-06 distinguishes automatic mapping from authored history; INS-03 protects
private annotation dependencies, outcomes and recipient projections. INS-05/10 retain
derived-context/geometry invalidation and INS-13 bounded capacity/stop responsibility.
MELT/RED/golden signals measure classification/publication success, refusal and latency
separately from external effects. USE tracks actual admitted comparisons/maps/staging
and counter saturation in declared logical units. STRIDE covers stale private/view
dependencies, false unchanged status, forged history participants and overflow.
LINDDUN covers hidden annotation activity inferred through counters/outcomes/timing.
Use bounded reasons and authorized aggregate/correlation fields, never raw target,
body, identity or global hidden-participant counts as public metric labels.

Open: every other companion/profile, complete current recipient/outcome/event/cache
noninterference, general target-history restoration, full invocation/replay integration,
actual concurrent candidate/root installation, native hosts, hostile decoding, physical
accounting, measurements, production refinement and independent assurance. Point
annotation storage remains a separate user-owned choice. No new component, transport,
public family/variant, parser runtime or undo-history policy is selected.
