# Actual parent settings query decoding

Existing F07 typed/dynamic operations now have a fixed decoded entry over the
actual settings reader and invocation owner. Original context/target references,
current scope, prepared cuts and native disclosure remain authoritative. No new
semantic operation, UI policy, filesystem mechanism, network transport or protected
verb is introduced. F07 ordinary decoding follows the existing ordinary-query
reservation pattern; F06's independent protected-control guarantee is different.

## Admission and canonical dispatch

Match the actual domain/pool before charging or traversing caller data. Charge the
fixed limit-classification cost to the actual parent, capture exact finite input
limits, then reserve seven maximum-request frames: envelope, authority, canonical
capture, limits, descriptor, current facts and producer envelope. Safe arithmetic
and actual parent headroom, not the pool's private nominal budget, govern admission.

For parent usage H, ceiling M, classification C and request bound B, admission
requires C ≤ M−H and 7B ≤ M−(H+C). The admitted temporary lease is C+7B and total
declared usage remains at most M. Every exit subtracts exactly the acquired lease;
it does not restore a stale absolute counter or refund retained pool capacity.
These are logical serialized-owner arguments, not physical peak or global proofs.

The native field declarations live in a shared immutable module to avoid a
reader/normalizer import cycle. Both guards consume the same forms. Capture retains
original context and target as separate opaque roles and owns ordinary request,
authority, limits and current-facts data. Dispatch only the fixed producer
envelope, captured scope and captured facts. Do not repair a foreign role from the
pool. Changes to caller data after capture cannot alter that semantic meaning.

Native-only entry retains its prior behavior when decoding is unused. The
compatibility corpus compares fourteen fixed JSON products, roots and parent/pool
ledgers against the prior candidate; this is not an all-profile or opaque-identity
equivalence proof.

## Refusal, fault and lifetime

Malformed input, foreign roles/scope, unknown profiles, unsupported limits and
ordinary pressure return unavailable and refund temporary workspace. Current
native loss remains absorbing; unknown facts only withhold. An unknown setting
key is a well-formed bound request, so trusted continuity loss still invalidates
its real context. A foreign handle cannot lend such a loss to another context.

The pool's busy fence refuses recursive decoded entry and context/pool retirement
until the temporary lease is discharged. An unexpected pre-dispatch decoding
failure sets an absorbing decoder fault on that actual pool, blocking new
preparations/acquisitions and both native/decoded delivery. It does not set the
execution domain's fault bit, modify the authored root, erase contexts/cuts or
refund their spent issuance and held pool charge. Pool fencing is distinct from
each context's invalidated flag; that flag alone is not delivery authority.

Clear busy and refund temporary workspace on every exit. Protected cut disposal,
owner stop, retention release, delivery drain and actual context/pool retirement
remain available after a decoder fault. Cuts unconsumed before dispatch still need
explicit disposal. Whole-pool retirement, not an unavailable result or temporary
refund, releases the retained parent charge. No reset/restart protocol is added.

## Instrumentation and scoped evidence

IF-01/02, PATH-02 and INS-01/03/05/07/08/12/13 distinguish classification/full
workspace admission, capture, native release, ordinary refusal, first decoder-pool
fault, busy state, retained obligations and protected discharge. MELT/golden/RED
track those stage/outcome populations, latency, errors and throughput; USE tracks
owned usage, saturation and refusal. STRIDE/LINDDUN/privacy/hazard coverage
challenges role/scope spoofing, post-capture tampering, denial of cleanup and
configuration/origin linkage. Never use raw requests, handles, targets, setting
keys/values, current-fact packets or malformed products as ordinary telemetry
labels or fault payloads. No new signal, numeric threshold or product default is
selected.

Eight controls cover fourteen native compositions, 66 refusals, twelve independent
boundaries and five absorbing-loss cases. Three fixed checkpoints cover 42 faults
and 84 reentries; fourteen post-capture cases change caller request/scope/facts,
and 42 early-refusal cases establish foreign pools reach no decoder checkpoint.
Probe assertion failures cannot be swallowed as expected injected faults.

Two banks detect 29 mutations against the complete gateway and checkpoint corpus.
Construction, syntax and process/tool failures do not count as semantic evidence.
Earlier 26 argument, 26 result/fault and 22 native-reader mutations remain acceptance
obligations. Selected substrate probes wrap 143 filesystem/process callables;
77 preconstructed fixtures execute eight controls without baseline calls and
detect three fixed read/rename/process injections. The observed selected engine
graph has 92 modules and excludes frontend modules, not arbitrary dynamic or
production linkage.

Full frozen qualification and endpoint reconciliation remain adoption gates.
Complete F07 discovery/public products, other families, raw hostile ingress,
actual policy/global/physical accounting, post-dispatch crash behavior,
operational measurements and independent refinement remain separate obligations.
