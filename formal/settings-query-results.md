# Native settings query results

Existing F07 operations return value, origins, capabilities or unavailable.
Closed frames, original context/target binding, captured payload meaning and
bounded release are separate obligations. No new operation, wire format, type
compiler or policy authority is introduced.

## Shape and captured meaning

Result declarations close the exact fields for each existing status. Unavailable
has status only. Successful products retain the original context and target;
value/origin queries retain the requested key. Origin and capability products use
permitted-only coverage. Declaration rows contain key, type, domain, scopes,
composition and sensitivity, never defaults or private layer identities.

Frame checks reject extra fields, nondata properties, unsupported prototypes,
non-dense arrays and unknown branches without coercing a status object. Type
descriptions remain normalized object-valued syntax trees. Their validity belongs
to the existing configuration compiler, not this result shape checker.

Native release separately compares values and ordered declaration rows with the
retained permitted projection. Origin arrays and per-map-field arrays must match
the projected origin IDs in order and restore the exact context-local reference
objects. Structural equality cannot authenticate those references. Both short and
overlong origin lists are independently challenged.

Check frame and captured meaning before reply preflight. A valid oversized reply
returns unavailable without invalidating the context; a smaller permitted query
can still succeed. After copying disclosed values/declarations, validate structure
and retained meaning again before release. Original origin references are not
cloned. Shape alone establishes neither current host permissions nor real
configuration applicability, complete origin coverage or accepted type semantics.

## Faults and discharge

An unexpected exception or result invariant failure in the bound trusted native
release path invalidates the affected context and withdraws its aliases. It
returns unavailable while retaining the context slot, declared pool charge and
spent issuance. It does not mutate the authored root, fault the execution domain
or control independent producer work.

An early exception may leave its prepared cut unconsumed; invalidation is not a
cut-consumption or disposal receipt. Protected cut disposal and context retirement
remain explicit. Context retirement still needs retention release and delivery
drain and does not refund pool capacity or lifetime issuance. Whole-pool retirement
requires all contexts and cuts discharged before refunding the parent charge.
Ordinary permission/capacity refusal is not an invariant fault or a restart grant.

All scans operate on finite accepted context/schema/projection bounds under
existing serialized trusted-data premises. Existing reply/capture reservations
remain controlling. Reflection, copied candidate construction, physical peak
allocation, concurrency/crash and hostile proxies remain outside these structural
arguments. Finite tests do not establish categorical or unbounded completeness.

## Instrumentation and evidence

IF-01/02, PATH-02 and INS-01/03/05/07/08/12/13 distinguish frame/binding checks,
bounded copy/release, transient pressure, first context invalidation, retained
capacity and protected discharge. MELT/golden/RED track those stage/outcome
populations, latency and error/throughput rates; USE tracks owned occupancy and
saturation. Count invalidation once, not each subsequent unavailable query.
STRIDE/LINDDUN/privacy/hazard coverage challenges reference substitution, changed
values, reordered declarations, raw origin linkage and premature resource release.
Do not log malformed products, raw handles, targets, setting keys/values or
permission packets as ordinary telemetry labels or fault payloads.

Seven product controls cover 28 native products, 71 malformed refusals and nine
independent origin-binding cases. Ten fixed fault stages each exercise fourteen
operation/key/route cases, including 98 faulted cases and fourteen early retained
cuts. Two banks detect 26 mutations against the complete product/fault corpus;
construction, syntax and process/tool failures do not count as semantic evidence.
The existing native reader retains all 22 mutation challenges.

Selected post-import probes wrap 143 filesystem/process callables. Nineteen
preconstructed fixtures execute seven controls and 28 native cases with no
baseline calls, detecting three fixed read/rename/process injections. The selected
engine graph contains 90 modules and excludes frontend modules; this is not static
production linkage or general host containment.

Full frozen qualification and endpoint reconciliation remain adoption gates.
Actual-parent decoded dispatch, full public result/discovery contracts, operational
measurements, host truth and independent refinement remain separate.
