# Validated unchanged success

D01 is adopted in requirements §5.7 and specification §6.4. A genuine semantic
no-op returns unchanged success after normal required validation, without an edit
publication generation, source revision or undo entry. This is not permission
to bypass currentness/authority/bounds, discard meaningful equal-text companions,
erase external-effect intent or promise replay/status retention.

## General conditional frame argument

Let P(S) contain the authoritative publication state and its edit bookkeeping.
For a supported request/profile, compute a bounded candidate semantic projection
C and declared effect intent E, before automatic commit bookkeeping. Required
source/selection/attachment/annotation/explicit history-intent participants must
be complete in that projection. Let V(S,r) mean the normal final preconditions
hold and no accepted cancellation/deadline has stopped the invocation.

Define identity as C equal to the current affected semantic projection and E
empty. The decision relation returns unchanged success exactly when V and identity
hold; this branch installs neither C nor automatic bookkeeping. It follows
directly that P(Safter)=P(Sbefore), where Sbefore is immediately before the
decision, not the preparation snapshot. Bounded separate invocation status is
outside this edit-publication projection, but still subject to normal resource
and recipient-release contracts.

Case analysis establishes the remaining distinctions. Invalid/stopped work cannot
succeed by identity. A differing companion makes the semantic projection differ
even when text equals. An effect-only intent prevents no-op classification even
if every local semantic value equals; the effect retains its own admission and
outcome contract rather than manufacturing an edit commit. Valid identity cannot
be falsely classified as a meaningful change just to create bookkeeping. No
automatic metadata is included in the identity test, avoiding circularity.

This argument is general for the stated relation, not a proof that actual
operation/profile classifiers are complete, pure or bounded. Such classifiers
must be sound and complete over their supported domain; unavailable comparison
evidence follows the declared refusal/bounded-deferral contract, never a guessed
identity or fabricated mutation. Concrete interpretation/grouping, provider and
implementation refinements remain separate.

## Bounded execution model

PS-NO (`NoOpPublication.tla`) imports EditorContracts' actual finite splice and
point-map operators, not its full temporal relation. One pending request/document,
three ASCII source characters and six transitions are explored. Nine reference
kinds cover empty input, same-text identity replacement, same-text replacement
with mapped target detachment, explicit selection, annotation body, group-close
intent, source change, effect intent and malformed input. These are fixtures,
not public verbs, selected endpoint affinities or source/annotation undo defaults.
The representative source-revision/history counters do not prove complete D13/
D19/D33/D45 profiles or establish structural-edit identity merely from bytes.

The final decision rechecks independent Boolean shape/grant/scope/read-only/
capacity/capability/context and exact-revision premises. Environmental source
edit then undo returns equal bytes with a fresh revision; that stale no-op must
still reject. An unrelated publication can proceed during preparation, and the
no-op compares/preserves immediately current state instead of restoring the old
coordinator root. Decision-time checks, before/after roots, foreign-stage and
diagnostic facts are frozen so later changes cannot accidentally satisfy a
witness for a different cause or order.

There are 43 configurations: twelve positive profiles (nine kinds plus diagnostic
off/full/fault), eleven weakened controls and twenty reachability witnesses.
Controls bypass validation, fabricate a change from identity, use text-only
classification for five meaningful companion/effect kinds, alter no-op bookkeeping,
restore a captured stale root, write through diagnostics or relabel a terminal
success after a diagnostic fault. Witnesses cover each kind, six isolated
non-source gate failures, equal-text stale revision, cancellation before/after,
an unrelated intervening commit and a diagnostic fault after unchanged success.
Each failure witness freezes its actual decision-time cause; terminal cancellation
and diagnostics cannot retroactively change the disposition.

All kinds have configured positive safety properties; controls must fail their
named invariant/action property, and witnesses must reach their named state.
Tool errors, horizon exhaustion without a witness and unrelated failures are not
accepted as evidence. An earlier 42-case targeted run checked the pre-completeness-
control version only; actual complete/current results must match the final
43-case manifest before claiming final execution.

## Symbolic local conditions

`noop-laws.smt2` adds four positive laws and four SAT fault controls. Positives
first require satisfiable premises, then refute negated unchanged framing,
invalid/stopped gating, meaningful equal-source companion publication and
effect-intent preservation. Semantic and automatic-bookkeeping arrays are
separate; the complete candidate projection and truthful eligibility are
premises, not something inferred from a content hash or source equality.

Controls exhibit identity-only validation bypass, source-only classification,
dropped equal-state effect intent and altered automatic bookkeeping. The exact
ordered `noopCases` manifest is checked under trusted Z3 4.15.4. These are local
encoding proofs, not proof-assistant replay, actual schema/permission/classifier
proofs or an implementation-refinement certificate.

## Conformance security and observation boundaries

Use IF-01/03, PATH-01 and INS-01/02 for bounded admission, preparation and final
disposition. Count validated unchanged successes separately from edit commits and
expected rejections; identity detection still consumes its applicable envelope.
Do not report no-op traffic as failures or manufactured useful publications.
Separate logical requests, attempts, participants, comparison cost and pending age.
Existing USE/RED/golden-signal and protected-health semantics remain applicable.

STRIDE challenges stale/forged identities, source-only classification, lost/torn
companion intent, fabricated commit attribution, high-volume cheap-looking
requests and diagnostic-triggered mutation. LINDDUN covers existence/activity
leakage from success, rejection, status tokens, counts and timing. Retain current
recipient-safe projection: unchanged success is not permission to disclose an
inaccessible object or participant list. IF-09 / INS-12 diagnostic capture/drain
cannot govern the authoritative disposition or expose raw content by default.

Implementation conformance must compare authoritative state before/after, not
infer unchanged framing from a single emitted event. Exercise malformed/stale/
denied/over-budget identity requests, relevant non-text changes, actual finite
ID/context reuse, explicit external effects, comparison exhaustion, races and
diagnostics off/full/fault. Native callbacks, real deadlines/allocators, complete
participant discovery, replay retention and provider effects remain unproved.
PS-CH stays text-changing-only; PS-NO does not close PH-09 or establish complete
cross-slice refinement. Second-agent review remains shared-artifact challenge,
not independent Cleanroom certification.
