# Closed annotation query results

The existing native F03 page, record, location and unavailable products are
validated before release. Exact outer fields come from annotation-queries.json;
the private normalized reader's `next` issuance intent does not become a public
continuation. Discovery /1–/5 and the three execution variants are unchanged.

## Values and authority

Pages bind the original snapshot and contain a dense array no larger than the
requested limit. Record aliases are unique and distinct from the continuation;
a nonterminal page is full. Inspection and location results retain the exact
requested annotation alias. Token shape alone does not establish registration,
current grants, scope or continuity.

Records have a reference and independently optional content and location facets.
Content has a string body and safe natural version. Location has a safe natural
target generation and a placement. Detached placement has only its state;
attached/affected placements have state, source revision and an existing canonical
target shape. Document, nonempty range and point targets retain the adopted
affinity and position/content profiles. Absent facets remain withheld, not null,
empty or detached. Shape checks do not verify UTF8 boundaries or placement against
source; the retained native capture and existing algorithms own those semantics.

The annotation/combined native owner checks final page aliases against its actual
staged/existing record and continuation mappings. The coherent owner checks the
aliases against its staged bindings for that retained member. These checks precede
selector installation and issuance. The facade checks closed values and request
identity without pretending to authenticate a fresh page token from its fields.
Direct native probes prevent the facade from masking an absent lower-level guard.

## Fault frames and resources

Malformed native construction faults admission and withholds the reply before
selector publication. A malformed native return caught later by the facade also
fences admission and returns only unavailable. If native publication already
occurred, the complete selector set and monotonic issuance remain installed;
facade refusal does not roll them back. The fixed late-result probe exercises
twelve fresh pages with three issued aliases each. Authored roots remain unchanged
and the existing seven-frame temporary facade workspace is refunded exactly.
Native retained obligations and protected retirement remain separate. This is not
general crash recovery or containment of arbitrary native code.

Validation retains no additional page or identity set. Duplicate detection scans
earlier admitted rows, using constant auxiliary live state and quadratic worst-case
comparisons in the bounded page length. Existing native page/reply reservations
remain in force. Actual physical/global accounting, scheduling and measured latency
require their own evidence; no new numeric default is asserted.

IF-01/02, PATH-02 and INS-01/03/05/08/12/13 distinguish native construction,
selector binding/publication, facade release, normal unavailable, prepublication
invariant faults and postpublication facade faults. MELT/golden/RED/USE separate
these populations, validation duration, page-size buckets and retained selector
pressure. STRIDE/LINDDUN/STPA/FMEA cover copied aliases, mixed roles, hidden-facet
disclosure, malformed refusal payloads, orphaned retained work and false rollback
claims. Bodies, locations, document identities and handles are not metric labels.

## Scoped evidence

- annotation-query-result-mutations.mjs checks 48 native products, 45 malformed
  products, five controls and 22 assertion-detected shape mutations.
- annotation-query-result-fault-mutations.mjs checks eight probes across 36 cases
  each and five guard mutations. Prepublication probes install no selectors;
  postpublication facade faults retain actual issuance. Malformed refusals release
  no extra data.
- annotation-query-result-substrate-checks.mjs wraps 143 post-import callables,
  observes zero baseline calls and detects three injected call types across 36
  cases each, with unchanged native/root frames and protected workspace refund.

Existing gateway construction targets are updated for local request/result
binding, preserving their challenges. Complete public result/discovery/event/
selector codecs, other operation families, hostile ingress, host/policy truth,
physical/global/concurrent/crash/measured refinement and independent assurance
remain separate. Full frozen verification and endpoint reconciliation are required
before adoption; no whole completion row closes.
